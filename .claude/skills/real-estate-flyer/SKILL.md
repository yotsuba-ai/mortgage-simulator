# 物件概要書からチラシを作る

概要書は「条件の一覧」で、チラシは「1〜2秒で読む理由を作る紙」。このスキルは
その変換を、印刷でずれない紙面と、出稿前の表示チェック込みで行う。

## 全体の流れ

```
概要書(PDF/Excel/CSV) → ① 読み取り → ② properties.json に正規化
                                          ↓
                          ③ 表示チェック（check_compliance.py）
                                          ↓
                          ④ キャッチ・アピールを書く
                                          ↓
                          ⑤ チラシHTML生成（build_flyer.py）→ ⑥ 目視確認・PDF化
```

先に②のデータを固めてから④の文章を書くこと。事実が確定していないうちにコピーを
書くと、概要書にない情報を書いてしまいやすく、それがそのまま不当表示になる。

## ① 概要書を読み取る

**PDF・スキャン画像**：Read ツールでそのまま開く。物件概要書は表組みのレイアウトに
意味がある（項目名と値が罫線で対応している）ので、テキスト抽出より画像として読むほうが
取り違えが少ない。ページ数が多い一覧表なら `pdfplumber` や `pdftotext -layout` も使える。

**Excel・CSV**：pandas か openpyxl で読む。どちらも無ければ
`soffice --headless --convert-to csv <file>` で変換する。1行1物件の一覧表になっている
ことが多いので、まず列名を全部出して、`references/property_schema.md` の対応表と突き合わせる。

**どの形式でも、読み取った値は必ず出典どおりに写す。** 概要書に書かれていない項目は
埋めない。「築年からしてRC造だろう」といった補完が、そのまま優良誤認の材料になる。

## ② properties.json に正規化する

キーの一覧・概要書の表記ゆれ対応表・単位の扱いは **`references/property_schema.md`** にある。
初めてこのスキルを使うときは必ず読む。要点だけ挙げると:

- 金額・面積は単位を外した数値で入れる（`3,480万円` → `34800000`、`68.52㎡` → `68.52`）
- 交通は `{"line","station","minutes"}` の配列。距離が分かれば `distance_m` も入れる
- 分からない項目はキーごと省く（`null` でもよい）。推測で埋めない

`examples/sample_properties.json` が全キーを使った実例になっている。

## ③ 表示チェックを先に通す

```bash
python3 scripts/check_compliance.py properties.json
```

ERROR が出たら **チラシを作る前に**直す。多くは概要書に載っている情報の写し忘れ
（取引態様・私道負担・建築条件など）なので、原本に戻れば埋まる。原本にも無ければ
「この項目が概要書に見当たらないので確認が必要」とユーザーに伝える。勝手に埋めない。

ERROR のうち「掲載可否（成約済み）」だけは直しようがない。その物件はチラシから外す。

判断の根拠と直し方は **`references/compliance.md`** にまとめてある。指摘の意味が
分からないとき、ユーザーから「この表現は使える？」と聞かれたときはここを読む。

## ④ キャッチコピーとアピールポイントを書く

書き方と面数ごとの文字数の目安は **`references/copywriting.md`**。折込チラシで実際に
読まれる順番（価格 → エリアと駅距離 → 間取り・面積 → 写真 → コピー）を踏まえてあるので、
コピーを書く前に一読する。

いちばん効くのは「この物件にしか書けないことを書く」。書いたコピーを他の物件に
貼り替えても成立するなら、その枠は何も言っていない。

書き終えたらもう一度 `check_compliance.py` を通す。コピーの中の「絶対」「格安」「駅近」
といった表現はここで捕まる。

## ⑤ チラシを組む

```bash
python3 scripts/build_flyer.py properties.json -o flyer.html
```

掲載件数から面数を自動で選び、余った枠は会社案内で埋める。件数ごとの割り付けは:

| 件数 | 面数 | 割り付け | 載る情報 |
|---|---|---|---|
| 1 | 1面 | 全面 | 写真・間取図・案内図・概要表（全項目）・アピール5点 |
| 2 | 2面 | 上下 | 写真＋間取図・価格・概要表・アピール3点 |
| 3 | 3面 | 3段 | 写真＋間取図・価格・主要8項目・アピール2点 |
| 4 | 4面 | 2×2 | 写真＋間取図・価格・主要5項目・アピール2点 |
| 5〜6 | 6面 | 2×3 | 同上（5件なら1枠が会社案内） |
| 7〜8 | 8面 | 2×4 | 写真1枚・価格・主要4項目・アピール1点 |
| 9 | 9面 | 3×3 | 同上 |
| 10〜12 | 12面 | 3×4 | 写真1枚・価格・間取り・面積・駅距離 |
| 13〜 | 12面×複数ページ | | |

枠が小さいほど項目を落とすのは意図的。8面に全項目を詰めると、価格すら読めない紙面になる。

主なオプション:

```bash
--per-page 6            # 面数を明示（4件を6面に載せて余白を作る、等）
--theme red             # blue(既定) / red / navy / green / warm / mono
--pdf flyer.pdf         # headless Chrome があればPDFも書き出す
--css custom.css        # スタイルの差し替え
```

**写真**：`photos` / `floorplan` / `map` に画像パスを入れると、HTMLにデータURIとして
埋め込まれる（HTML1枚を印刷所に渡せる）。未指定なら枠だけが点線で残るので、
写真待ちの状態でも紙面の確認と入稿準備が進められる。

## ⑥ 確認して渡す

生成後、`build_flyer.py` が出す「注意」（コピーが長すぎる等）を潰す。自動で切り詰めると
文が途中で切れて広告にならないので、短く書き直す。

紙面を目視確認したいときは、ブラウザで開くか、Chromium があればスクリーンショットを撮る:

```bash
chromium --headless --disable-gpu --no-sandbox --virtual-time-budget=4000 \
  --window-size=794,1123 --screenshot=preview.png file://$PWD/flyer.html
```

**PDF化**：`--pdf` が使えなければ、ブラウザで開いて「印刷 → PDFに保存」。
用紙 A4／余白なし／**背景のグラフィックを印刷する** をオンにする（帯とタグの色が消えるため）。

ユーザーには HTML（と PDF）のパス、面数と割り付け、表示チェックの結果、
写真の差し込み待ちがあればその旨を伝える。

## よくある調整

- **1物件を目立たせたい**：`properties` の先頭に置く。1面・2面レイアウトでは先頭が最大枠
- **同じ物件を種別違いで出したい**：`--per-page` を変えて2回生成すれば、折込用（12面）と
  店頭用（1面）を同じデータから作り分けられる
- **余白が寂しい**：件数より多い `--per-page` を指定すると会社案内枠が入る
- **色を会社のトーンに合わせたい**：`--theme` で足りなければ `assets/flyer.css` の
  `:root` の `--accent` / `--price` を書き換える
- **賃貸物件**：このスキルは売買・収益を前提にしている。賃貸に使うなら `price` に賃料、
  `price_note` に「／月」を入れ、敷金・礼金・共益費を `notes` に書く。ただし賃貸には
  賃貸固有の必要表示事項があるので、`references/compliance.md` の範囲外だと伝える

## ファイル

| パス | 中身 |
|---|---|
| `scripts/build_flyer.py` | JSON → A4チラシHTML。面数の自動選択と割り付け |
| `scripts/check_compliance.py` | 必要表示事項の欠落と使えない表現の検出 |
| `references/property_schema.md` | JSONの全キー、概要書の表記ゆれ対応表、単位の正規化 |
| `references/compliance.md` | 表示ルールの根拠と直し方 |
| `references/copywriting.md` | コピーの書き方、面数ごとの文字数、種別ごとの訴求軸 |
| `assets/flyer.css` | A4印刷用スタイル。面数ごとの寸法もここ |
| `examples/sample_properties.json` | 全キーを使った実例（6物件） |
