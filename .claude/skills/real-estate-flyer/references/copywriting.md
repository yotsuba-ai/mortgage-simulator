# キャッチコピーとアピールポイントの書き方

概要書は「条件の一覧」で、チラシは「読む理由を作る紙」。同じ情報でも並べ方と
言葉の選び方で反応が変わる。ここでは折込・ポスティングという媒体を前提にする。

## 1. 折込チラシで読まれる順番

新聞折込やポスティングは、捨てられるまでに1〜2秒しかない。その間に見られるのは

1. **価格**（数字の大きさで真っ先に目に入る）
2. **エリアと駅からの距離**（自分に関係があるか）
3. **間取り・面積**（住めるか）
4. **写真**
5. キャッチコピー

という順。テンプレートもこの順で強弱を付けてある。だからキャッチコピーは
「価格と駅距離では伝わらない、この物件だけの理由」を書く場所になる。
価格や間取りをコピーで繰り返すのは枠の無駄づかい。

## 2. キャッチコピーの作り方

型としては **「具体的な事実」＋「暮らしのイメージ」** が扱いやすい。

- 事実だけ：「2025年12月リフォーム済」→ 情報。読み飛ばされる
- イメージだけ：「理想の暮らしがここに」→ どの物件にも書ける。意味がない
- 両方：「2025年リフォーム済。荷物を置いたその日から暮らせる3LDK」

**この物件にしか書けないことを書く**、が唯一のコツ。書いたコピーを他の物件に
貼り替えても成立するなら、それは何も言っていない。

避ける表現は `references/compliance.md` の6章にまとめてある。
「絶対」「格安」「駅近」のたぐいは規制に触れるうえ、具体性がないので効きも悪い。

## 3. 面数ごとの文字数の目安

枠が小さくなるほどコピーは短くする。溢れると `build_flyer.py` が警告を出す。

| 掲載件数 | レイアウト | キャッチ（全角） | アピールポイント |
|---|---|---|---|
| 1件 | 1面 | 20〜34字 | 4〜5個 / 各12〜24字 |
| 2〜3件 | 2面・3面 | 20〜28字 | 2〜3個 / 各10〜20字 |
| 4〜6件 | 4面・6面 | 16〜24字 | 2個 / 各8〜16字 |
| 7〜9件 | 8面・9面 | 12〜18字 | 1個 / 各8〜14字 |
| 10件〜 | 12面 | 10〜14字 | なし（価格と駅距離だけが読まれる） |

12面のときにコピーを凝っても読まれない。逆に1面のときは、写真・間取図・概要表が
全部載るので、コピーは「この紙で何を伝えたいか」を宣言する役割を担える。

## 4. 種別ごとの訴求軸

何を書くか迷ったら、その種別で買い手が実際に比較している軸から選ぶ。

### 中古マンション
管理状態（修繕履歴・管理形態）／リフォームの有無と時期／向き・階数・角部屋／
駅距離／管理費・修繕積立金の水準／学区／ペット可・宅配ボックスなどの規約と設備

### 中古戸建
土地の広さと形／駐車台数／庭・日当たり／リフォーム履歴／接道と再建築の可否／
生活動線（スーパー・学校までの距離）

### 新築戸建
住宅性能（長期優良住宅・耐震等級・省エネ基準）／標準装備／建物保証／
入居可能時期／全◯棟のうちの区画の良さ

### 土地
建築条件の有無（条件なしは大きな訴求）／整形地かどうか／接道と幅員／
インフラ引込済みか／用途地域と建てられる規模／擁壁・高低差の有無

### 収益物件
表面利回りと前提（満室想定か現況か）／稼働率とレントロールの開示可否／
築年数と融資期間の見通し／間取タイプの入替えやすさ／管理会社の引継ぎ可否

## 5. アピールポイントの書き方

- **数字を入れる**：「広いリビング」→「リビング16.5帖」
- **距離で書く**：「学校が近い」→「◯◯小学校まで徒歩5分（約400m）」
- **時期を書く**：「リフォーム済」→「2025年12月に水回り・内装を全面リフォーム」
- **1項目1メッセージ**：詰め込むと読まれない
- **概要表と重複させない**：間取り・面積・築年は表に出るので、ポイント欄では繰り返さない

## 6. 良い例・悪い例

**中古マンション**
- ✗ 「駅近の格安物件！絶対おすすめの掘り出し物です」
  （「駅近」「格安」「絶対」「掘り出し物」がいずれも規約違反。中身も何もない）
- ○ 「荻窪駅徒歩8分。2025年リフォーム済みの南向き角部屋」

**土地**
- ✗ 「夢のマイホームを実現できる最高の土地」
- ○ 「建築条件なしの整形地96.44㎡。上下水道・都市ガス引込済み」

**収益物件**
- ✗ 「利回り7％超！儲かる一棟アパート」
- ○ 「高円寺駅徒歩6分・全8戸。表面利回り7.32％（満室想定／現況満室）」

**新築戸建**
- ✗ 「完璧な設備の新築住宅」
- ○ 「長期優良住宅認定。食洗機・浴室乾燥機を標準装備した4LDK」
