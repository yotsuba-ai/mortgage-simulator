# 不動産広告の表示ルール

折込チラシ・ポスティングチラシも当然この規制の対象。`check_compliance.py` は
このうち機械的に判定できる部分を自動化したもので、この文書は判断の根拠と、
指摘が出たときの直し方をまとめている。

法令の最終的な解釈・出稿の可否は宅地建物取引業者の判断による。迷う表現は
不動産公正取引協議会に確認するのが実務上いちばん早い。

## 1. 根拠になっている3つのルール

| ルール | 広告に効いてくるところ |
|---|---|
| 宅地建物取引業法 | 誇大広告の禁止（32条）、取引態様の明示（34条）、広告開始時期の制限（33条：未完成物件は建築確認後でないと広告できない） |
| 景品表示法 | 優良誤認（実際より良く見せる）・有利誤認（価格や条件を得に見せる）の禁止 |
| 不動産の表示に関する公正競争規約・同施行規則 | 必要表示事項、特定用語の使用基準、二重価格表示、おとり広告の禁止。実務上いちばん細かく効くのはこれ |

## 2. 1枚のチラシに必ず入れるもの（広告主の表示）

- 事業者名（会社名）
- 宅地建物取引業の免許証番号（例: 東京都知事(3)第123456号）
- 事務所の所在地・電話番号

`build_flyer.py` はこれをフッターとして全ページに刷り込む。`company` が欠けていると
チェッカーが ERROR を出す。

## 3. 物件ごとに必ず書くもの

枠が小さい 8面・12面レイアウトでも省略できない。テンプレートは
どの面数でも `取引態様` を描画するように作ってある。

- **取引態様**：売主／代理／媒介（専属専任・専任・一般）のいずれか
- **所在地**
- **交通の利便**：最寄駅名と徒歩所要時間（またはバス利用の場合は停留所と所要時間）
- **価格**：消費税を含む総額。未定なら「未定」と書く（予告広告の要件を満たす場合のみ）
- **面積**：建物面積（マンションは専有面積）／土地面積。単位は㎡
- **築年月**：建物がある物件は必須

## 4. 種別ごとの追加項目

### 土地・新築戸建
- **私道負担の有無**：負担がなくても「無」と明示する
- **建築条件の有無**：建築条件付なら、条件の内容（一定期間内に指定業者と建築請負契約を結ぶこと）も
- **接面道路**：種別（公道／私道）・幅員・接面距離
- 再建築できない土地は「**再建築不可**」と明示
- 市街化調整区域は「**市街化調整区域。宅地の造成及び建物の建築はできません。**」を16ポイント以上の大きさで
- 傾斜地・高圧線下・古家付きなど、価格や利用に影響する事情は明示

### 中古マンション
- 管理費・修繕積立金（月額）
- 所在階／建物の階数
- 敷地の権利形態（所有権・借地権）

### 中古戸建
- 土地・建物それぞれの面積
- 増改築の履歴があればその旨

## 5. 使い方が決まっている用語

| 用語 | 使える条件 |
|---|---|
| 新築 | 建築後1年未満 **かつ** 未入居。どちらか欠けたら使えない |
| 中古 | 上記に当たらない建物 |
| リフォーム済／リノベーション済 | **工事の内容と時期**を併記する（例：2025年12月に内装全面リフォーム／水回り・建具） |
| 完成予定 | 建築確認を受けた後でないと広告自体ができない |
| 駅から徒歩◯分 | 道路距離80mを1分として計算し、端数は切り上げ。信号待ちや坂は考慮しない |
| 即入居可 | 実際に引渡し可能な時期を併記する |
| 予告広告 | 「予告広告」と明示し、本広告を行う旨と時期を書く。価格未定が許されるのはこの場合 |
| 分譲済／完売 | 事実である場合のみ。事実なら掲載自体を取り下げる |

## 6. 使えない表現と言い換え

チラシは「良く見せたい」圧力がいちばん強く働くところ。抽象的な褒め言葉を、
**物件の事実**に置き換えると、規制も通るうえに読者の反応もよくなる。

| 使えない／危ない | なぜ | 言い換えの方向 |
|---|---|---|
| 完全、完璧、絶対、万全 | 全く欠けるところがないことを意味する。証明できない | 具体的な設備・仕様を書く |
| 日本一、業界一、No.1、最高級、抜群 | 客観的な調査結果の裏付けが要る | 「◯◯区で専有80㎡以上は当社取扱の3件のみ」など事実で |
| 格安、激安、破格、掘り出し物、投売り | 有利誤認。値下げなら二重価格表示の要件が要る | 「◯月◯日 価格改定（5,200万円→4,980万円）」と事実を書く |
| 特選、厳選、イチオシ | 選定基準を示せないと使えない | 何がよいのかを具体的に書く |
| 値上がり確実、必ず儲かる、利回り保証 | 将来の断定は誇大広告 | 実績値と前提条件を書く |
| 駅前、駅近、一等地、好立地 | あいまい | 「◯◯駅 徒歩4分（約280m）」 |
| 完売、残りわずか（事実でない） | おとり広告 | — |

「南向き」「角部屋」「リフォーム済（時期・内容併記）」「小学校まで徒歩5分」のような、
**確認できる事実**は問題なく使える。チラシの訴求力はここで作る。

## 7. 距離・面積・時間の書き方

- **徒歩所要時間**：道路距離80m＝1分、端数切り上げ。起点はマンションなら建物の出入口、
  戸建・土地なら敷地。`access[].distance_m` を入れておくとチェッカーが検算する
- **バス利用**：停留所名、バス乗車時間、停留所から物件までの徒歩時間をそれぞれ書く
- **面積**：㎡表示。坪を併記するのは可（本テンプレートは自動で括弧書きする）
- **各種施設までの距離**：道路距離で。「◯◯小学校まで480m」のように書く
- **価格**：消費税等を含む総額。1戸単位。予定価格は「予定価格」と明示

## 8. 収益物件の利回り表示

- 表面利回りか実質利回りかを必ず明示する
- 満室想定の場合は「満室想定」と書き、**現況の稼働状況も併記**する
- 想定賃料を使うなら、それが現行賃料でないことが分かるようにする
- 利回りの保証・断定はできない

例：`"yield_label": "表面利回り（満室想定）"` ＋ `"current_status": "賃貸中（稼働率100％）"`

## 9. おとり広告

成約済み・売主の都合で取引できない・そもそも存在しない物件を載せるのは禁止。
チラシは印刷から配布まで日数が空くので、**入稿直前に販売状況を洗い直す**のが実務上の要点。
`current_status` に「成約」「契約済」「商談中」などが入っているとチェッカーが ERROR にする。
