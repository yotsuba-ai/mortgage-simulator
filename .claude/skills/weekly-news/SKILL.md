# 週刊 不動産ニュース

毎週木曜配信の不動産ニュース記事を作成する。リポジトリは `yotsuba-ai/mortgage-simulator`、記事の置き場所は `news/`。

## 前提の確認

作業前に必ず読む。

1. `news/README.md` — 情報ソース一覧・記事フォーマット・執筆ルールの正本
2. `news/` 内の最新の `YYYY-MM-DD.md` — 直近号。**前号と同じ数値をそのまま繰り返さない**。その後に新しく公表されたデータを優先する

## 手順

### 1. 情報収集

**必ず `WebSearch` を使う。`WebFetch` と `curl` はこの環境のネットワークポリシーでブロックされており、egress 403 で失敗するので試さない。**

`allowed_domains` でソースを絞った検索を複数回投げる。最低限カバーするテーマ:

- **その週に新しく公表された統計・ニュース** — これを「今週の一番」として冒頭に置く
- 新築分譲マンション市場動向（不動産経済研究所）
- 中古マンションの成約価格・成約件数（レインズ、アットホーム）
- 新築戸建価格・募集家賃動向（アットホーム）
- 住宅市場・購入者動向（SUUMOジャーナル）
- 投資用不動産の市況・融資動向（楽待新聞、健美家）
- 住宅ローン金利と日銀の金融政策
- 地価（公示地価・基準地価・路線価）、制度・法改正、業界動向

前号の「来週以降のウォッチポイント」に挙がっている項目は、進展がないか必ず確認する。

### 2. 記事の作成

`news/YYYY-MM-DD.md` を作成する。日付は**発行日＝その週の木曜日**。

**当日付のファイルが既に存在する場合でも、処理をスキップせず内容を更新する。** 前回の収集日以降に公表された情報を反映し、より重要な材料が出ていれば「今週の一番」を差し替える。冒頭の「データ収集日」は必ず当日に更新する。

構成は `news/README.md` の記事フォーマットに従う。

1. **今週の3行まとめ** — ここだけ読めば要点が掴める
2. **本編6〜8本** — 冒頭は「今週の一番」。各項目に数値の表と「読みどころ」
3. **来週以降のウォッチポイント** — 次に見るべき指標・イベント
4. **情報ソース** — 参照元へのリンク一覧

### 3. 執筆ルール

- 数値には必ず**時点**を添える（○年○月時点、○年上半期など）
- 「首都圏」「東京都」「都心3区」など**集計範囲を混同しない**
- **推測と事実を区別する**。解釈は「読みどころ」の中で、そうと分かる書き方にする
- 一次資料が確認できなかった数値は、その旨を注記する
- 住宅ローン金利の話題では `../index.html` の住宅ローンシミュレーターへの導線を入れる
- **単なる要約で終わらせない。** 「読みどころ」では数字の裏側にある意味を解説する。数字を並べ直しただけの記事には価値がない

### 4. バックナンバー表の更新

`news/README.md` のバックナンバー表に今週号の行を追加する。既に当該号の行がある場合は、内容欄を最新の見出しに書き換える。

### 5. コミットと push

ブランチ `claude/weekly-real-estate-news-wbiosc` にコミットして push する。

```
git push -u origin claude/weekly-real-estate-news-wbiosc
```

ブランチが存在しない場合、または既存の PR がマージ済みの場合は main から作り直す。

```
git fetch origin main && git checkout -B claude/weekly-real-estate-news-wbiosc origin/main
```

作り直した場合に限り force-with-lease を使ってよい。

**PR は明示的に依頼されない限り作成しない。**

### 6. 報告

`SendUserFile` で作成した記事ファイルをユーザーに送り、3行まとめを添えて日本語で報告する。

## 既知の制約

- **外部サイトへの直接アクセスがブロックされている。** `athome.co.jp` / `suumo.jp` / `rakumachi.jp` / `mlit.go.jp` などへの WebFetch・curl は egress 403 で失敗する。数値はウェブ検索経由で取得した各社の公表値であり、一次資料の原本にあたっての確認はできない。記事末尾にこの旨を注記すること
- 各サイトを直接読ませたい場合は、環境のネットワーク設定で対象ドメインを許可リストに追加する（[Claude Code on the web のドキュメント](https://code.claude.com/docs/en/claude-code-on-the-web)）

## 定期実行との関係

このスキルは定期実行（Routine）からも手動からも呼べる。スケジュール設定は `news/ROUTINE.md` を参照。

Routine が発火しなかった場合は、任意のセッションで `/weekly-news` と打てば同じ記事が作れる。
