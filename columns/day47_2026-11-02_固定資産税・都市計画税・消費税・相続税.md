# Day 47（2026年11月2日）固定資産税・都市計画税・消費税・相続税の基礎

## 今日のテーマ

所得税以外の、賃貸経営に関わる税金を一気に整理します。**固定資産税・都市計画税**は毎年の保有コスト、**消費税**は家賃の課税関係、**相続税**は賃貸経営の大きな動機です。それぞれ数字が問われます。

## まず結論

1. 固定資産税は**1月1日の所有者**に課税、標準税率**1.4%**。**住宅用地の特例**で200㎡以下の部分は課税標準が**6分の1**、超える部分は**3分の1**。都市計画税は市街化区域内、制限税率**0.3%**、住宅用地は**3分の1・3分の2**。
2. **住宅の家賃**（1か月以上の貸付け）は消費税**非課税**。事務所・店舗の家賃、住宅に付随しない駐車場代、管理報酬、仲介手数料は**課税**。
3. 相続税では、賃貸中の土地は**貸家建付地**、建物は**貸家**として評価が下がる。**小規模宅地等の特例**で貸付事業用宅地は**200㎡まで50%減額**。

## 本文

### 固定資産税

| 項目 | 内容 |
|---|---|
| 納税義務者 | **1月1日**時点の固定資産課税台帳上の所有者（年の途中で売買しても、その年はもとの所有者が納税義務者。実務では日割精算） |
| 課税主体 | 市町村（東京23区は都） |
| 課税標準 | 固定資産税評価額（**3年ごと**に評価替え） |
| 税率 | **標準税率1.4%**（市町村が条例で変更可） |
| 免税点 | 土地30万円、家屋20万円、償却資産150万円未満は課税されない |
| 納期 | 年4回（自治体により異なる） |

**住宅用地の特例**（課税標準の軽減）
- **小規模住宅用地**（住戸1戸あたり**200㎡以下**の部分）: 評価額の**6分の1**
- **一般住宅用地**（200㎡を超える部分、家屋の床面積の10倍まで）: 評価額の**3分の1**
- アパートの敷地は「戸数×200㎡」まで小規模住宅用地になるため、賃貸住宅を建てると土地の固定資産税が大幅に下がる
- 空家等対策特別措置法により、**特定空家**や**管理不全空家**として勧告を受けると、この特例の対象から除外される（Day 50）

**新築住宅の減額**
- 新築後**3年間**（3階建以上の耐火・準耐火構造は**5年間**）、床面積**120㎡まで**の部分の税額が**2分の1**に減額（一定の床面積要件あり。時限措置のため期限を確認）

### 都市計画税

- **市街化区域内**の土地・家屋に課税（市街化調整区域は原則非課税）
- 税率は**制限税率0.3%**（これを超えられない）
- 住宅用地の特例: 小規模住宅用地**3分の1**、一般住宅用地**3分の2**
- 固定資産税とあわせて納付

### その他の取得・契約時の税

- **不動産取得税**: 取得時に1回、都道府県税。標準税率4%（住宅・土地は特例で**3%**）。新築住宅は評価額から**1,200万円**控除（長期優良住宅は1,300万円）。宅地は評価額の2分の1が課税標準
- **登録免許税**: 所有権移転登記等に課税
- **印紙税**: **建物の賃貸借契約書は非課税**（印紙不要）。**土地の賃貸借契約書は課税**。管理受託契約書は、委任契約なら非課税だが請負の性質があれば課税文書になり得る。金銭の領収書は5万円以上で課税（営業に関しないものは非課税）

### 消費税

| 取引 | 課税・非課税 |
|---|---|
| **住宅の家賃**（貸付期間1か月以上） | **非課税** |
| 住宅の**礼金・更新料・共益費** | 非課税（家賃と同様） |
| 住宅の**敷金**（返還されるもの） | 不課税（資産の譲渡等でない） |
| 住宅の貸付期間が**1か月未満**（ウィークリーマンション等） | 課税 |
| **事務所・店舗**の家賃 | **課税** |
| **駐車場**の使用料（住宅に付随せず独立して貸すもの） | **課税**。住宅の家賃に含めて貸す場合は非課税 |
| 管理業者の**管理報酬** | 課税 |
| **仲介手数料** | 課税 |
| 土地の譲渡・貸付け | 非課税 |
| 建物の譲渡 | 課税 |

住宅家賃は非課税なので、住宅のみを貸すオーナーは通常、消費税の納税義務者になりません（課税売上高が1,000万円以下）。インボイス制度でも、住宅家賃についてはインボイス発行の必要がありません。

### 相続税・贈与税

**相続税の基礎控除**: 3,000万円＋600万円×法定相続人の数

**賃貸不動産の評価**
- **貸家建付地**（賃貸建物の敷地）: 自用地評価額 × (1 − 借地権割合 × 借家権割合（30%） × 賃貸割合)
- **貸家**（賃貸建物）: 固定資産税評価額 × (1 − 借家権割合（30%） × 賃貸割合)
- 賃貸割合は、賃貸中の床面積の割合。空室が多いと評価減が小さくなる（一時的な空室は賃貸中とみなされる場合あり）

**小規模宅地等の特例**
- **貸付事業用宅地**: **200㎡まで、50%減額**
- 特定居住用宅地（自宅）: 330㎡まで80%減額
- 特定事業用宅地: 400㎡まで80%減額
- 相続開始前3年以内に貸付けを始めた宅地は原則として貸付事業用宅地の特例の対象外（事業的規模で貸付けを行っていた場合を除く）

現金で持っているより賃貸不動産にしたほうが相続税評価額が下がるため、相続対策として賃貸住宅が建てられます。サブリース勧誘の背景の一つでもあります。

**贈与税**: 暦年課税の基礎控除は年110万円。相続時精算課税制度（2,500万円まで非課税、令和6年から年110万円の基礎控除も）。

## ひっかけポイント

- 「固定資産税の納税義務者は、**4月1日**時点の所有者」→ 誤り。1月1日。
- 「小規模住宅用地の課税標準は評価額の**3分の1**」→ 誤り。6分の1。3分の1は一般住宅用地。
- 「都市計画税の税率は**1.4%**」→ 誤り。制限税率0.3%。
- 「**住宅の家賃**には消費税が課税される」→ 誤り。非課税。
- 「**事務所**の家賃は消費税非課税」→ 誤り。課税。
- 「建物の賃貸借契約書には**印紙**が必要」→ 誤り。非課税文書。
- 「小規模宅地等の特例で、貸付事業用宅地は**330㎡まで80%減額**」→ 誤り。200㎡まで50%減額。

## 確認問題（○×）

**問1** 固定資産税は、毎年1月1日現在の固定資産の所有者に課税される。

**問2** 住宅用地のうち1戸あたり200㎡以下の部分については、固定資産税の課税標準が評価額の6分の1となる。

**問3** 住宅の貸付け（貸付期間1か月以上）に係る家賃は、消費税が非課税である。

**問4** 建物の賃貸借契約書は、印紙税の課税文書ではない。

**問5** 相続税の計算において、賃貸中の建物の敷地は貸家建付地として、自用地よりも低く評価される。

### 解答と解説

- **問1 ○** 賦課期日は1月1日。
- **問2 ○** 小規模住宅用地の特例。
- **問3 ○** 住宅家賃は非課税。
- **問4 ○** 印紙不要。
- **問5 ○** 借地権割合×借家権割合×賃貸割合の分だけ評価減。
