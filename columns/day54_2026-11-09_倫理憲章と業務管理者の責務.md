# Day 54（2026年11月9日）賃貸不動産経営管理士の倫理憲章と業務管理者の責務

## 今日のテーマ

**賃貸不動産経営管理士「倫理憲章」**と、賃貸不動産経営管理士・業務管理者として求められる姿勢を扱います。毎年1問程度、倫理憲章の内容や、事例に対する「望ましい対応」を問う形で出題されます。条文暗記というより、「専門家としてどう振る舞うべきか」という常識的判断で解ける問題が多いです。

## まず結論

1. 倫理憲章は**7項目**: ①公共的使命、②法令の遵守と信用保持、③信義誠実の義務、④公正と中立性の保持、⑤専門的サービスの提供および自己研鑽の努力、⑥能力を超える業務の引き受け禁止、⑦秘密を守る義務。
2. 賃貸不動産経営管理士は、**試験合格 → 登録**（実務経験2年または実務講習）→ **5年ごとの更新**。業務管理者として営業所の管理・監督を担う（Day 3）。
3. 賃貸不動産経営管理士は、貸主（依頼者）の利益を図りつつ、入居者の居住の安定にも配慮し、**公正・中立**な立場を保つ。

## 本文

### 倫理憲章（一般社団法人賃貸不動産経営管理士協議会）

前文で、賃貸不動産経営管理士が「賃貸不動産の管理に関する専門家として、賃貸住宅の入居者の居住の安定と賃貸事業の公正かつ円滑な実施に貢献する」ことをうたい、7項目を定めています。

| 項目 | 内容（要旨） |
|---|---|
| **1 公共的使命** | 公共的使命を常に自覚し、公正な業務を通じて公共の福祉に貢献する |
| **2 法令の遵守と信用保持** | 関係する法令とルールを遵守し、**品位**を保持して、賃貸不動産経営管理士全体の信用を傷つける行為をしない |
| **3 信義誠実の義務** | 信義に従い誠実に職務を執行し、**依頼者等**に対し重要な事項について故意に告げず、または不実のことを告げない |
| **4 公正と中立性の保持** | 常に公正で中立な立場で職務を行い、業務上の判断に必要な事実の把握に努める。利害関係者間の紛争を助長・誘発しない |
| **5 専門的サービスの提供および自己研鑽の努力** | 高い専門性を保持し、常に研鑽して知識・技能を向上させ、質の高いサービスを提供する |
| **6 能力を超える業務の引き受け禁止** | 自らの能力や知識を超える業務を引き受けない |
| **7 秘密を守る義務** | 正当な理由なく、職務上知り得た秘密を他に漏らさない。**職務を退いた後も**同様 |

出題では、「依頼者の利益のためなら法令に反してもよい」「知識が不足していても引き受けて後から勉強すればよい」「退職後は守秘義務がない」といった記述が誤りとして出ます。

### 賃貸不動産経営管理士の登録

- **登録試験**（毎年11月）に合格
- **登録**: 合格後、**2年以上の実務経験**または**実務講習の修了**が必要。登録を受けると「賃貸不動産経営管理士」を名乗り、登録証が交付される
- **更新**: 登録の有効期間は**5年**。更新には更新講習の修了が必要
- 登録の取消し: 不正登録、欠格事由該当、倫理憲章違反による信用失墜など
- 令和3年の管理業法施行に伴い、賃貸不動産経営管理士は**業務管理者**の要件として**国家資格**に位置づけられた

### 業務管理者としての責務（復習を兼ねて）

業務管理者（Day 3）は、営業所における次の事項の**管理・監督**を担います。

- 管理受託契約の重要事項説明・締結時書面の適正な実施
- 維持保全の実施方法の妥当性
- 家賃等の分別管理
- 帳簿の備付け、定期報告
- 秘密の保持、苦情処理
- 従業者への指導・教育

業務管理者は、自ら説明することは義務ではありませんが、**部下が行う業務が法令に適合しているか**を確認する立場です。違反を見過ごせば、管理業者が監督処分を受け、業務管理者自身も信用を失います。

### 公正・中立と利益相反

管理業者は貸主から委託を受けており、貸主の利益のために業務を行います。しかし同時に、入居者に対しても誠実に対応する必要があります。

- **入居者からの苦情**を貸主に隠さず報告し、貸主の判断を仰ぐ
- **貸主の違法な要求**（自力救済、不当な原状回復請求、差別的な入居拒否）には応じない。法令とガイドラインに基づく助言をする
- **自社の利益**（工事の発注先、保険の紹介、関連会社への誘導）と貸主の利益が対立する場面では、事実を開示し貸主の判断に委ねる
- **相見積**をとり、不当に高い工事を発注させない
- 貸主・入居者双方から**金銭や利益の供与を受けない**

### コンプライアンス体制

- 法令・ガイドラインの社内周知、研修
- 苦情・相談窓口の整備
- 内部通報制度
- 反社会的勢力の排除
- 個人情報保護（Day 51）

### 事例で考える

**事例1** 貸主から「滞納者の部屋の鍵を替えてほしい」と頼まれた。
→ 自力救済で違法（Day 44）。法令の遵守（倫理憲章2）に基づき断り、法的手続を助言する。

**事例2** 入居者から「上階の騒音がひどい」と苦情を受けたが、上階の入居者は貸主の親族だった。
→ 公正と中立性（倫理憲章4）に基づき、事実を確認したうえで通常どおり対応し、貸主に報告する。

**事例3** 設備の専門知識が必要な大規模修繕の監理を依頼された。
→ 自社に知識・体制がなければ引き受けず（倫理憲章6）、専門家（建築士等）の関与を提案する。

**事例4** 退職した元従業者が、前職で知ったオーナーの資産状況を営業に使った。
→ 秘密を守る義務（倫理憲章7）と管理業法21条（Day 7）に違反。

## ひっかけポイント

- 「倫理憲章の秘密保持義務は、**在職中に限られる**」→ 誤り。退職後も。
- 「賃貸不動産経営管理士は、**依頼者の利益を最優先**し、入居者の利益は考慮しなくてよい」→ 誤り。公正・中立、入居者の居住の安定にも配慮。
- 「自らの能力を超える業務でも、**依頼があれば**引き受けるべき」→ 誤り。
- 「賃貸不動産経営管理士の登録に**有効期間はない**」→ 誤り。5年。
- 「試験に合格すれば、**登録しなくても**賃貸不動産経営管理士を名乗れる」→ 誤り。登録が必要。

## 確認問題（○×）

**問1** 賃貸不動産経営管理士は、自らの能力や知識を超える業務を引き受けてはならない。

**問2** 賃貸不動産経営管理士は、職務を退いた後であれば、職務上知り得た秘密を他に漏らしても倫理憲章に反しない。

**問3** 賃貸不動産経営管理士は、常に公正で中立な立場で職務を行い、利害関係者間の紛争を助長・誘発してはならない。

**問4** 賃貸不動産経営管理士の登録の有効期間は5年であり、更新を受けるには更新講習の修了が必要である。

**問5** 賃貸不動産経営管理士は、依頼者である貸主の指示であれば、法令に反する行為であっても実行しなければならない。

### 解答と解説

- **問1 ○** 倫理憲章6。
- **問2 ×** 退職後も秘密保持義務。
- **問3 ○** 倫理憲章4。
- **問4 ○** 登録の更新。
- **問5 ×** 法令の遵守（倫理憲章2）。
