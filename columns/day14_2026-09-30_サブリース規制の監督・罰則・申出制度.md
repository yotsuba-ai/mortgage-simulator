# Day 14（2026年9月30日）サブリース規制の監督・罰則・国土交通大臣への申出制度

## 今日のテーマ

サブリース規制の締めくくりとして、国土交通大臣の**監督**（指示・業務停止命令）、**申出制度**、そして罰則の一覧を整理します。管理業者の監督処分（Day 8）との違いを意識してください。サブリース業者には「登録」がないので、**登録取消しという処分は存在しません**。

## まず結論

1. 監督処分は**指示 → 業務停止命令（1年以内）**の2段階。どちらも**公表**される。勧誘者に対しては勧誘の停止。
2. **何人も**、特定賃貸借契約の適正化のため必要があると認めるときは、国土交通大臣に**申し出て**適当な措置を求めることができる。
3. 罰則は「**6月・50万円**」（不実告知等、業務停止命令違反）、「**50万円**」（重説、締結時書面）、「**30万円**」（誇大広告、閲覧、報告・検査拒否）の3段階。

## 本文

### 指示（法33条）

国土交通大臣は、特定転貸事業者が**28条〜32条**（誇大広告、不当勧誘、重説、締結時書面、閲覧）に違反したとき、または勧誘者が**28条・29条**に違反したときは、その者に対し、違反の是正のため必要な措置をとるべきことを**指示**することができます。

**勧誘者が違反した場合、勧誘者本人だけでなく、その勧誘者に勧誘を行わせた特定転貸事業者に対しても指示ができます**。業者が勧誘者に「言い過ぎておいて」と暗に求めることを防ぐためです。

指示をしたときは、その旨を**公表**しなければなりません。

### 業務停止命令（法34条）

国土交通大臣は、次の場合、**1年以内の期間を定めて**、特定賃貸借契約の締結について**勧誘を行い、または勧誘者に勧誘を行わせることを停止**し、または特定賃貸借契約に関する業務の全部もしくは一部を停止すべきことを命ずることができます。

- 28条〜32条に違反した場合で、特に必要があると認めるとき
- 指示に従わないとき

勧誘者に対しては、**勧誘の停止**を命じます。命令をしたときは**公表**します。

業務停止命令違反は**6月以下の懲役もしくは50万円以下の罰金、または併科**です。

### 申出制度（法35条）

**何人も**、特定賃貸借契約の適正化を図るため必要があると認めるときは、国土交通大臣に対し、その旨を申し出て、適当な措置をとるべきことを求めることができます。国土交通大臣は、申出があったときは**必要な調査**を行い、申出の内容が事実であると認めるときは、指示・業務停止命令などの**適当な措置をとらなければなりません**。

「何人も」なので、契約当事者のオーナーだけでなく、**入居者、競合業者、地域住民、業界団体**など誰でも申し出ることができます。申出は書面・電子メールなど任意の方法で行えます。

### 報告徴収・立入検査（法36条）

管理業者と同様、国土交通大臣は特定転貸事業者・勧誘者に報告を求め、立入検査をすることができます。拒否・虚偽報告は**30万円以下の罰金**です。

### 罰則一覧（サブリース規制）

| 違反行為 | 罰則 |
|---|---|
| 故意の事実不告知・不実告知（29条1号） | 6月以下の懲役もしくは50万円以下の罰金、または併科 |
| 業務停止命令違反（34条） | 6月以下の懲役もしくは50万円以下の罰金、または併科 |
| 重要事項説明義務違反（30条） | 50万円以下の罰金 |
| 締結時書面交付義務違反（31条） | 50万円以下の罰金 |
| 誇大広告等の禁止違反（28条） | 30万円以下の罰金 |
| 書類の閲覧義務違反（32条） | 30万円以下の罰金 |
| 報告徴収・立入検査の拒否等（36条） | 30万円以下の罰金 |
| 威迫・迷惑時間・再勧誘等（29条2号） | 罰則なし（指示・業務停止のみ） |

法人の従業者が違反した場合は**法人にも罰金**が科されます（両罰規定）。

### 管理業者の監督との比較

| 項目 | 管理業者 | 特定転貸事業者・勧誘者 |
|---|---|---|
| 最初の処分 | 業務改善命令 | 指示 |
| 業務停止 | 1年以内 | 1年以内 |
| 登録取消し | あり | なし（登録制度がない） |
| 公表 | 登録取消しは公告 | 指示・業務停止命令ともに公表 |
| 申出制度 | なし | あり（何人も） |

## ひっかけポイント

- 「国土交通大臣は、特定転貸事業者の**登録を取り消す**ことができる」→ 誤り。登録制度がない。
- 「申出ができるのは、特定賃貸借契約の**当事者に限られる**」→ 誤り。何人も。
- 「勧誘者が違反した場合、指示は**勧誘者に対してのみ**行われる」→ 誤り。勧誘を行わせた特定転貸事業者にも可能。
- 「業務停止命令の期間は**2年以内**」→ 誤り。1年以内。
- 「指示をしても**公表されない**」→ 誤り。公表される。
- 「誇大広告等の禁止違反は**50万円以下**の罰金」→ 誤り。30万円以下。

## 確認問題（○×）

**問1** 国土交通大臣は、勧誘者が不当な勧誘等の禁止に違反した場合、その勧誘者に勧誘を行わせた特定転貸事業者に対しても指示をすることができる。

**問2** 特定賃貸借契約の適正化のため必要があると認めるときは、何人も国土交通大臣に申し出て、適当な措置をとるべきことを求めることができる。

**問3** 国土交通大臣は、特定転貸事業者が業務停止命令に違反した場合、その登録を取り消すことができる。

**問4** 業務停止命令に違反した特定転貸事業者は、6月以下の懲役もしくは50万円以下の罰金に処せられ、またはこれを併科される。

**問5** 国土交通大臣は、特定転貸事業者に対して指示をしたときは、その旨を公表しなければならない。

### 解答と解説

- **問1 ○** 法33条。
- **問2 ○** 申出制度は「何人も」。
- **問3 ×** 特定転貸事業者に登録制度はない。
- **問4 ○** サブリース規制で最も重い罰則。
- **問5 ○** 指示・業務停止命令ともに公表。
