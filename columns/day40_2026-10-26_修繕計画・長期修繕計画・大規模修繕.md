# Day 40（2026年10月26日）修繕計画・長期修繕計画・大規模修繕

## 今日のテーマ

第3期で学んだ各部位の劣化を、**計画的に**直していく仕組みが**長期修繕計画**です。修繕周期の目安、計画の作り方、税務上の**修繕費と資本的支出**の区分、工事発注の実務を整理します。

## まず結論

1. 長期修繕計画は、部位ごとの**修繕周期と概算費用**を**30年程度**の期間で一覧化し、**5年程度ごとに見直す**。周期の目安は外壁塗装・屋上防水が10〜15年、給水管更新が20〜30年、鉄部塗装が4〜6年。
2. 税務上、**修繕費**は支出年の経費、**資本的支出**は資産計上して減価償却。判定は「価値を高めるか、耐久性を増すか」だが、**20万円未満**、**おおむね3年以内の周期**、**60万円未満または取得価額の10%以下**などの形式基準で修繕費とできる。
3. 工事発注は、**仕様書**を作成して**相見積**をとり、工事監理と完了検査を行う。入居者への事前周知と工事中の安全確保が必要。

## 本文

### 長期修繕計画とは

建物の各部位・設備について、**いつ、何を、いくらで**修繕するかを長期間にわたって計画したものです。分譲マンションでは国土交通省の「長期修繕計画標準様式・作成ガイドライン」があり、賃貸住宅でもこれを参考に作成します。

- 計画期間: **30年程度**以上（大規模修繕を2回含む期間が望ましい）
- 見直し: **5年程度ごと**（劣化状況や物価の変動を反映）
- 構成: 建物の概要、部位ごとの修繕項目・周期・概算費用、年度ごとの支出予定、資金計画
- 目的: 突発的な支出を避け、資金を計画的に準備する。オーナーへの提案資料にもなる

### 修繕周期の目安

| 部位・設備 | 修繕周期の目安 | 内容 |
|---|---|---|
| **鉄部塗装**（手すり、階段、扉） | **4〜6年** | 錆止め・塗装 |
| **外壁塗装** | **10〜15年** | 塗替え、シーリング打替え |
| **屋上防水** | **10〜15年** | 防水層の改修 |
| **給湯器** | 10〜15年 | 交換 |
| **エアコン** | 10〜15年 | 交換 |
| **給水ポンプ** | 10〜15年 | 交換・オーバーホール |
| **受水槽** | 20〜25年 | 交換 |
| **給水管・排水管** | **20〜30年** | 更新または更生（ライニング） |
| **エレベーター** | 25〜30年 | リニューアル |
| **屋根（勾配屋根）** | 20〜30年 | 葺替え |
| **キッチン・ユニットバス** | 15〜25年 | 交換 |

### 大規模修繕

外壁・屋上防水・鉄部などをまとめて行う工事を**大規模修繕**といい、12〜15年周期が一般的です。足場を組む必要があるため、足場を共用してまとめて工事するほうが経済的です。実施前に**建物診断**（劣化診断）を行い、修繕範囲と工法を決めます。

### 修繕費と資本的支出

賃貸経営の税務では、修繕にかかった支出が**修繕費**（その年の必要経費）か**資本的支出**（固定資産に計上し減価償却）かで、所得計算が大きく変わります。

**原則的な考え方**
- **修繕費**: 通常の維持管理、原状回復のための支出（壊れた部分を同程度に直す）
- **資本的支出**: 資産の**価値を高め**、または**耐久性を増す**支出（グレードアップ、用途変更、増築）

**形式基準（修繕費とできるもの）**
- 1件の支出が**20万円未満**
- **おおむね3年以内の周期**で行われる修繕
- 修繕費か資本的支出か明らかでない場合で、**60万円未満**、または**前期末取得価額の10%以下**

例: 外壁の塗替えは原則修繕費、外壁に断熱材を追加すれば資本的支出。給湯器を同等品に交換すれば修繕費、ワンランク上の多機能型に変えれば差額部分が資本的支出。

### 工事発注の実務

1. **現況調査・劣化診断**: 専門業者による調査で修繕範囲を確定
2. **仕様書の作成**: 工事範囲、工法、材料、数量を明示。仕様が曖昧だと見積が比較できない
3. **相見積**: 複数業者（3社程度）から同一仕様で見積をとる。極端に安い見積は仕様落ちや追加費用のリスク
4. **契約**: 請負契約書（建設業法により書面義務）、工期、支払条件、**契約不適合責任**（瑕疵担保）の期間
5. **工事監理**: 仕様どおりに施工されているか確認。必要に応じて第三者（建築士）に委託
6. **完了検査・引渡し**: 検査記録、竣工図、保証書を受領し保存
7. **記録の保存**: 修繕履歴は次回の計画と資産価値の証明に使う

建設業の許可は、500万円以上（建築一式は1,500万円以上等）の工事を請け負う業者に必要です。

### 入居者への配慮

- 工事の**事前周知**（掲示・書面）: 期間、時間帯、騒音・振動、足場・養生、バルコニー使用制限、防犯上の注意
- 工事中の**安全確保**: 通路の確保、資材の飛散防止、足場からの侵入防止（施錠、センサー）
- 騒音・臭気が避けられない工事は、入居者の在宅時間を考慮する
- 入居中に室内工事が必要な場合は、入居者の**同意**を得て日程を調整する

## ひっかけポイント

- 「長期修繕計画は、一度作成すれば**見直しの必要はない**」→ 誤り。5年程度ごとに見直す。
- 「鉄部塗装の周期は**10〜15年**」→ 誤り。4〜6年。
- 「建物の**価値を高める**支出は修繕費として一括で経費計上できる」→ 誤り。資本的支出。
- 「1件**30万円未満**の支出は修繕費とできる」→ 誤り。20万円未満。
- 「相見積は、**仕様を各業者に任せて**とるのがよい」→ 誤り。同一仕様で比較する。

## 確認問題（○×）

**問1** 長期修繕計画は、建物や設備の劣化状況、物価の変動等を踏まえ、定期的に見直す必要がある。

**問2** 外壁塗装や屋上防水の修繕周期は、一般に10〜15年程度が目安とされる。

**問3** 建物の価値を高め、または耐久性を増すための支出は、税務上、資本的支出として資産に計上し減価償却する。

**問4** 1件の修繕にかかる支出が20万円未満の場合、税務上、修繕費として処理することができる。

**問5** 修繕工事の見積を複数の業者からとる場合、比較を容易にするため、同一の仕様書に基づいて見積を依頼することが望ましい。

### 解答と解説

- **問1 ○** 5年程度ごとの見直し。
- **問2 ○** 修繕周期の目安。
- **問3 ○** 資本的支出の定義。
- **問4 ○** 形式基準。
- **問5 ○** 相見積の基本。
