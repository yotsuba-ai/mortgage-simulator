# Day 45（2026年10月31日）敷金精算と会計処理の基礎（企業会計原則・仕訳）

## 今日のテーマ

退去時の**敷金精算**の実務と、賃貸経営・管理業に必要な**会計の基礎**です。会計は毎年1問程度、企業会計原則や仕訳の考え方が出ます。深入りせず、用語と基本構造を押さえます。

## まず結論

1. 敷金精算は、**明渡し → 原状回復費用等の確定 → 敷金からの控除 → 残額の返還**の順。借主は敷金返還と明渡しの**同時履行を主張できない**（Day 22）。**精算書**で内訳を明示する。
2. 企業会計原則の一般原則は**真実性・正規の簿記・資本取引と損益取引の区分・明瞭性・継続性・保守主義・単一性**の7つ。
3. 貸主にとって**敷金は預り金（負債）**、**礼金は収益**。管理業者にとって収納した家賃は**預り金**、管理報酬は**売上**。

## 本文

### 敷金精算の流れ

1. **退去立会い**: 室内の状態を入居時のチェックリスト・写真と比較し、損傷箇所を記録。借主に確認・署名をもらう
2. **費用の確定**: 原状回復費用（Day 27のガイドラインに基づき負担区分と経過年数を反映）、未払賃料・共益費、日割り賃料、鍵交換費用（借主負担の場合）などを算出
3. **精算書の作成**: 敷金額、控除項目ごとの金額と根拠、返還額（または不足額）を明示
4. **返還または請求**: 残額を借主の指定口座に返還。不足があれば請求。返還時期は「明渡し後遅滞なく」で、契約書で「明渡し後1か月以内」などと定める例が多い
5. **オーナーへの報告**: 精算結果の報告と、オーナー負担分の修繕手配

精算をめぐる紛争を防ぐには、**入居時の記録**、**ガイドラインに沿った負担区分**、**見積の明示**が重要です。

### 企業会計原則の一般原則

| 原則 | 内容 |
|---|---|
| **真実性の原則** | 企業の財政状態・経営成績について真実な報告をする |
| **正規の簿記の原則** | すべての取引を正確な会計帳簿に記録する（複式簿記） |
| **資本取引・損益取引区分の原則** | 資本取引（出資など）と損益取引（売上・費用）を区別する |
| **明瞭性の原則** | 利害関係者に会計事実を明瞭に表示する |
| **継続性の原則** | 採用した会計処理の方法を毎期継続して適用し、みだりに変更しない |
| **保守主義の原則** | 予想される損失は計上し、予想される利益は計上しない（慎重な処理） |
| **単一性の原則** | 目的別に異なる形式の財務諸表を作っても、基礎となる記録は一つ |

### 複式簿記と仕訳

複式簿記では、1つの取引を**借方（左）**と**貸方（右）**に同じ金額で記録します（仕訳）。

| 区分 | 増加 | 減少 |
|---|---|---|
| 資産（現金、預金、建物、未収金） | 借方 | 貸方 |
| 負債（借入金、預り金、未払金） | 貸方 | 借方 |
| 純資産（資本金） | 貸方 | 借方 |
| 収益（賃料収入、礼金収入） | 貸方 | 借方 |
| 費用（修繕費、管理費、減価償却費） | 借方 | 貸方 |

**発生主義**: 現金の収支ではなく、取引の発生時点で収益・費用を計上する（企業会計の原則）。**現金主義**: 現金の収支時点で計上する（小規模な個人事業で一部認められる）。

### 貸主の会計処理の例

| 取引 | 借方 | 貸方 |
|---|---|---|
| 敷金20万円を受け取った | 現金預金 200,000 | **預り金（敷金）** 200,000 |
| 礼金10万円を受け取った | 現金預金 100,000 | **礼金収入（収益）** 100,000 |
| 家賃8万円が入金された | 現金預金 80,000 | 賃料収入 80,000 |
| 修繕費5万円を支払った | 修繕費 50,000 | 現金預金 50,000 |
| 退去時、敷金から原状回復費3万円を控除し17万円返還 | 預り金 200,000 | 現金預金 170,000 ／ 雑収入（または修繕費の戻し）30,000 |

敷金は返還義務のある**負債**であって、受け取っても収益にはなりません。礼金や敷引金など返還不要の金銭は**収益**です。

### 管理業者の会計処理の例

| 取引 | 借方 | 貸方 |
|---|---|---|
| 入居者から家賃8万円を収納した | 現金預金（管理口座） 80,000 | **預り金** 80,000 |
| 管理報酬4千円を控除してオーナーに送金した | 預り金 80,000 | 現金預金 76,000 ／ **管理報酬（売上）** 4,000 |

管理業者にとって収納した家賃は自分の売上ではなく、オーナーに渡すべき**預り金**です。これが分別管理（Day 6）の会計的な意味です。

### 財務諸表

- **貸借対照表（B/S）**: ある時点の**財政状態**（資産・負債・純資産）
- **損益計算書（P/L）**: 一定期間の**経営成績**（収益・費用・利益）
- **キャッシュフロー計算書**: 現金の流れ

サブリース業者が閲覧に供する書類（Day 13）は、この貸借対照表と損益計算書です。

## ひっかけポイント

- 「敷金を受け取ったとき、貸主は**収益**として計上する」→ 誤り。預り金（負債）。
- 「礼金は、契約終了時に借主に**返還**するため負債として計上する」→ 誤り。返還不要で収益。
- 「**保守主義の原則**とは、予想される利益を早期に計上すること」→ 誤り。予想損失は計上し、予想利益は計上しない。
- 「**継続性の原則**により、会計処理の方法は毎期変更しなければならない」→ 誤り。みだりに変更しない。
- 「管理業者が収納した家賃は、管理業者の**売上**として計上する」→ 誤り。預り金。

## 確認問題（○×）

**問1** 敷金の精算において、借主は敷金の返還を受けるまで建物の明渡しを拒むことができる。

**問2** 企業会計原則の継続性の原則とは、いったん採用した会計処理の方法をみだりに変更してはならないというものである。

**問3** 貸主が敷金を受領した場合、会計上は預り金として負債に計上する。

**問4** 貸主が礼金を受領した場合、会計上は収益として計上する。

**問5** 発生主義とは、現金の収入・支出があった時点で収益・費用を計上する考え方である。

### 解答と解説

- **問1 ×** 明渡しが先履行。
- **問2 ○** 継続性の原則。
- **問3 ○** 返還義務があるため負債。
- **問4 ○** 返還不要のため収益。
- **問5 ×** 現金主義の説明。発生主義は取引の発生時点で計上。
