# Day 16（2026年10月2日）管理業法 総復習②（サブリース規制）

## 今日のテーマ

第1期の後半（Day 9〜14）、**サブリース規制**の総ざらいです。管理業者規制との**違い**を軸に整理します。サブリース規制の問題は、事例（広告文や勧誘トーク）を読ませて「違反か否か」を判断させる形式が多いので、後半に事例判断のトレーニングを入れました。

## まず結論

1. サブリース規制の主語は「**特定転貸事業者**」と「**勧誘者**」。登録不要、戸数無関係。
2. 勧誘者にかかるのは**誇大広告・不当勧誘の2つだけ**。書面3種（重説・締結時書面・閲覧）は特定転貸事業者のみ。
3. 罰則は「**6月・50万円**」「**50万円**」「**30万円**」「**なし**」の4段階。

## 本文

### 1. 定義の境界線

| 事例 | 判断 |
|---|---|
| 業者がオーナーから借り上げ、入居者に転貸 | 特定賃貸借契約に**該当** |
| オーナーの親族・関連会社が借り上げて転貸 | **該当しない**（密接関係者） |
| 企業が社宅として借り上げ、従業員に使わせる | 原則**該当しない**（転貸事業ではない） |
| 社宅代行業者が借り上げて企業に転貸 | **該当** |
| 業者から依頼を受けて知人にサブリースを勧める既存オーナー | 勧誘者に**該当** |
| 勧誘者からさらに委託を受けた者 | 勧誘者に**該当** |
| 依頼を受けずに自主的にサブリースを紹介する者 | 勧誘者に**該当しない** |

### 2. 5つの規制と主体

| 規制 | 特定転貸事業者 | 勧誘者 | 罰則 |
|---|---|---|---|
| 誇大広告等の禁止（28条） | ○ | ○ | 30万円 |
| 不当な勧誘等の禁止（29条） | ○ | ○ | 1号: 6月・50万円 ／ 2号: なし |
| 重要事項説明（30条） | ○ | × | 50万円 |
| 締結時書面（31条） | ○ | × | 50万円 |
| 書類の閲覧（32条） | ○ | × | 30万円 |

### 3. 数字の総整理

| 数字 | 何の数字か | Day |
|---|---|---|
| 1週間程度 | 重説から契約締結までに置くことが望ましい期間 | 12 |
| 3か月以内 | 業務状況調書等の作成期限（事業年度経過後） | 13 |
| 3年間 | 業務状況調書等の備置き期間 | 13 |
| 1年以内 | 業務停止命令の期間 | 14 |
| 6月・50万円 | 不実告知等、業務停止命令違反の罰則 | 11・14 |

### 4. 管理業者規制との対比

| 項目 | 管理業者 | サブリース業者 |
|---|---|---|
| 登録 | 200戸以上で義務 | 制度なし |
| 重説の罰則 | なし | 50万円 |
| 締結時書面の罰則 | 30万円 | 50万円 |
| 帳簿／閲覧書類 | 帳簿5年保存、閲覧義務なし | 調書等3年備置き、閲覧義務あり |
| 最初の監督処分 | 業務改善命令 | 指示（公表） |
| 登録取消し | あり | なし |
| 申出制度 | なし | あり（何人も） |

### 5. 事例判断トレーニング

次の各事例が違反かどうか、根拠条文とともに判断してみてください。

**事例A** チラシに「30年間家賃保証」と大きく記載し、裏面の隅に小さく「家賃は2年ごとに見直します」と記載した。
→ **誇大広告等に該当し得る**。打消し表示は本体表示と近接した場所に同程度の大きさで記載する必要がある。

**事例B** 営業担当者が、オーナーから「減額はありますか」と聞かれ、契約書に減額条項があることを知りながら「減額はありません」と答えた。
→ **不当な勧誘等（不実告知）に該当**。6月以下の懲役もしくは50万円以下の罰金。

**事例C** 「検討します」と言って帰ったオーナーに、翌日から毎日電話をかけた。
→ 契約しない旨の意思表示がまだなければ直ちに再勧誘の禁止には当たらないが、**私生活の平穏を害する方法**として不当な勧誘等に該当し得る。明確に断られた後の電話は再勧誘の禁止に該当。

**事例D** 特定賃貸借契約の重要事項説明を、契約締結の翌日に行った。
→ **違反**。契約締結前に行う必要がある。

**事例E** 相手方が宅建業者だったので、締結時書面を交付しなかった。
→ **違反**。締結時書面に相手方の除外規定はない。

**事例F** 契約前のオーナー候補から損益計算書の閲覧を求められ、「まだ契約していないので」と断った。
→ **違反**。相手方となろうとする者にも閲覧させる義務がある。

## ひっかけポイント（総集編）

- 「特定転貸事業者は**登録**が必要」→ 不要
- 「勧誘者にも**重説義務**」→ なし
- 「誇大広告は**実際に誤認した人がいて**初めて違反」→ 誤認させるような表示で足りる
- 「**過失**による不告知も懲役刑」→ 故意が要件
- 「威迫は**30万円の罰金**」→ 罰則なし（監督処分のみ）
- 「閲覧できるのは**契約済みの相手方**だけ」→ 契約前の者も
- 「サブリース業者の**登録を取り消す**」→ 登録がないので不可
- 「申出は**当事者**のみ」→ 何人も

## 確認問題（○×）

**問1** 勧誘者は、誇大広告等の禁止および不当な勧誘等の禁止の規制を受けるが、重要事項説明義務は負わない。

**問2** 特定転貸事業者が、契約書に家賃減額条項があることを知りながら、勧誘に際して「家賃が減額されることはない」と告げた場合、6月以下の懲役もしくは50万円以下の罰金に処せられることがある。

**問3** 業務状況調書等の閲覧を求めることができる者には、特定賃貸借契約の相手方となろうとする者も含まれる。

**問4** 特定転貸事業者が締結時書面の交付義務に違反した場合の罰則は、賃貸住宅管理業者が管理受託契約の締結時書面の交付義務に違反した場合の罰則と同じである。

**問5** 国土交通大臣は、特定転貸事業者に対し、1年以内の期間を定めて業務の停止を命ずることができる。

### 解答と解説

- **問1 ○** 勧誘者には広告・勧誘の規制のみ。
- **問2 ○** 故意の不実告知。
- **問3 ○** 契約前の者にも閲覧させる。
- **問4 ×** サブリースは50万円以下、管理受託契約は30万円以下。
- **問5 ○** 法34条。
