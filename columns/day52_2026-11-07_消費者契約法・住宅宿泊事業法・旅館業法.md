# Day 52（2026年11月7日）消費者契約法・住宅宿泊事業法・旅館業法

## 今日のテーマ

賃貸借契約の特約の有効性を左右する**消費者契約法**と、賃貸住宅と隣接する**民泊**の規制（住宅宿泊事業法・旅館業法）を扱います。消費者契約法はDay 19（更新料）、22（敷引）、26・49（追い出し条項）で登場した判例の根拠法です。

## まず結論

1. 消費者契約法は、**消費者**（事業として契約する者を除く個人）と**事業者**の契約に適用される。貸主が個人でも、賃貸を**事業として**行っていれば事業者。
2. 不実告知・断定的判断の提供・不利益事実の不告知・困惑類型による契約は**取り消せる**（8〜10条は**無効**）。**10条**は「消費者の利益を一方的に害する条項」を無効にする一般条項で、更新料・敷引は「高額すぎなければ有効」、追い出し条項は無効。
3. 住宅宿泊事業（民泊新法）は**届出制**で、年間**180日**が上限。**家主不在型**は**住宅宿泊管理業者**（国土交通大臣登録）への委託が義務。賃貸住宅で民泊を行うには、**転貸**に当たるため貸主の承諾が必要。

## 本文

### 消費者契約法の適用範囲

- **消費者**: 個人（事業として、または事業のために契約の当事者となる個人を除く）
- **事業者**: 法人その他の団体、および事業として契約の当事者となる個人
- 居住用の賃貸借で借主が個人なら借主は消費者。貸主は、法人はもちろん、個人でも**反復継続して賃貸**していれば事業者に当たる（1室だけでも事業性が認められることがある）。したがって多くの賃貸借契約に適用される
- 事務所・店舗の賃貸借で借主が事業者の場合は適用されない

### 取消しができる場合（4条）

**誤認類型**
- **不実告知**: 重要事項について事実と異なることを告げた
- **断定的判断の提供**: 将来の変動が不確実な事項について断定的判断を提供した（「家賃は絶対下がらない」）
- **不利益事実の不告知**: 利益になることを告げ、不利益になる事実を故意（または重過失）に告げなかった

**困惑類型**
- **不退去**（帰ってほしいと言ったのに帰らない）、**退去妨害**（帰りたいと言ったのに帰さない）
- 社会生活上の経験不足の不当な利用、加齢等による判断力の低下の不当な利用、霊感等による知見を用いた告知、契約前の債務の内容の実施など

取消権は、追認できる時から**1年**（霊感商法は3年）、契約締結から**5年**（同10年）で消滅します。

### 無効になる条項（8〜10条）

| 条文 | 内容 | 賃貸借での例 |
|---|---|---|
| **8条** | 事業者の損害賠償責任を**全部免除**する条項、故意・重過失による責任を一部免除する条項、責任の有無や限度を事業者が決定する条項 | 「貸主は設備の故障によりいかなる損害が生じても責任を負わない」 |
| **8条の2** | 消費者の解除権を放棄させる条項 | 「借主はいかなる場合も契約を解除できない」 |
| **9条** | 解除に伴う損害賠償の予定・違約金のうち**平均的な損害を超える部分**、遅延損害金の**年14.6%を超える部分** | 「中途解約時は残期間の賃料全額を支払う」の過大部分 |
| **10条** | 法令の任意規定より消費者の権利を制限し義務を加重する条項で、信義則に反して**消費者の利益を一方的に害する**もの | 判例で判断が分かれる（下記） |

### 10条をめぐる判例（復習）

| 条項 | 判断 |
|---|---|
| **更新料**特約 | 額が高額すぎるなど特段の事情がない限り**有効**（最判平成23年7月15日） |
| **敷引**特約 | 額が高額すぎなければ**有効**（最判平成23年3月24日） |
| **定額補修分担金**特約（下級審） | 事案により判断が分かれる |
| 保証会社の**無催告解除・明渡しみなし条項** | **無効**（最判令和4年12月12日） |
| 通常損耗を借主負担とする特約 | 消費者契約法以前に、明確な合意がなければ契約内容にならない（最判平成17年12月16日） |

### 住宅宿泊事業法（民泊新法）

| 項目 | 内容 |
|---|---|
| 対象 | 住宅に人を宿泊させる事業で、年間の宿泊日数が**180日以下**のもの |
| 手続 | 都道府県知事等への**届出**（許可ではない） |
| **住宅宿泊事業者** | 届出をして民泊を行う者。宿泊者名簿の備付け、衛生・安全の確保、外国人宿泊者への対応、**標識の掲示**、近隣への説明・苦情対応、都道府県知事への定期報告（2か月ごと） |
| **家主不在型** | 事業者が住宅に居住していない場合、**住宅宿泊管理業者**に管理を**委託しなければならない**（家主居住型で一定規模以下なら委託不要） |
| **住宅宿泊管理業者** | **国土交通大臣の登録**（5年更新）。管理受託契約の重要事項説明、締結時書面など、管理業法と似た規制 |
| **住宅宿泊仲介業者** | **観光庁長官の登録**。宿泊者と事業者の仲介（民泊サイト） |
| 条例による制限 | 都道府県等は、生活環境の悪化を防ぐため区域・期間を限定して実施を制限できる |

**賃貸住宅で民泊を行う場合**
- 借主が借りている部屋で民泊を行うことは、**転貸**に当たります。貸主の**承諾**がなければ無断転貸として解除事由になります（Day 24）
- 届出には、賃貸住宅の場合、貸主が民泊を承諾していることを証する書類が必要です
- 分譲マンションでは管理規約で禁止されていないことの確認が必要です
- 民泊として現に使われている届出住宅は、管理業法上の「賃貸住宅」から除外されます（Day 1）

### 旅館業法

- ホテル営業・旅館営業（現在は**旅館・ホテル営業**に統合）、**簡易宿所営業**、下宿営業の**許可制**（都道府県知事等）
- 180日を超えて宿泊事業を行うには旅館業法の許可が必要
- 構造設備基準、宿泊者名簿、感染症対策等の義務
- 旅館業の施設は管理業法上の「賃貸住宅」から除外

### 国家戦略特区の特区民泊

国家戦略特別区域法に基づき、自治体の**認定**を受けて行う民泊で、**2泊3日以上**（自治体により異なる）の滞在が条件。180日制限はありません。特区民泊で現に使われている施設も、管理業法上の「賃貸住宅」から除外されます。

## ひっかけポイント

- 「貸主が**個人**であれば、消費者契約法は適用されない」→ 誤り。事業として賃貸していれば事業者。
- 「消費者契約法により、**更新料特約は無効**」→ 誤り。高額すぎなければ有効。
- 「消費者契約法により、遅延損害金の上限は年**20%**」→ 誤り。年14.6%。
- 「住宅宿泊事業は、都道府県知事の**許可**が必要」→ 誤り。届出。
- 「住宅宿泊事業は年間**365日**営業できる」→ 誤り。180日以下。
- 「**家主居住型**の民泊は、住宅宿泊管理業者への委託が義務」→ 誤り。義務は家主不在型。
- 「借主が貸主に**無断で**民泊を行っても、住宅宿泊事業法の届出をしていれば問題ない」→ 誤り。無断転貸。

## 確認問題（○×）

**問1** 個人が反復継続して賃貸住宅を貸している場合、その個人は消費者契約法上の事業者に該当し得る。

**問2** 消費者契約法9条により、賃貸借契約における遅延損害金の利率を年14.6%を超えて定めた場合、その超える部分は無効となる。

**問3** 住宅宿泊事業法に基づく住宅宿泊事業は、都道府県知事等への届出により行うことができ、年間の宿泊日数は180日を超えてはならない。

**問4** 住宅宿泊事業者が届出住宅に居住していない家主不在型の民泊では、住宅宿泊管理業者に管理を委託しなければならない。

**問5** 賃貸住宅の借主が貸主の承諾を得ずに住宅宿泊事業を行うことは、無断転貸として契約解除の原因となり得る。

### 解答と解説

- **問1 ○** 事業性があれば事業者。
- **問2 ○** 9条2号。
- **問3 ○** 届出制と180日制限。
- **問4 ○** 家主不在型の委託義務。
- **問5 ○** 転貸に当たる。
