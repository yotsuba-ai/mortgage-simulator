# Day 48（2026年11月3日）保険（火災保険・地震保険・借家人賠償責任保険）

## 今日のテーマ

賃貸経営のリスクを移転する**保険**です。貸主が入る保険と借主が入る保険、それぞれの役割と、**失火責任法**との関係を整理します。地震保険の数字は頻出です。

## まず結論

1. **火災保険**は火災のほか落雷・破裂爆発・風災・雹災・雪災・水災・水濡れ・盗難などを補償するが、**地震・噴火・津波**による損害は対象外で、**地震保険**（火災保険に付帯）が必要。
2. 地震保険の保険金額は火災保険の**30〜50%**、建物**5,000万円**・家財**1,000万円**が上限。損害区分は**全損100%・大半損60%・小半損30%・一部損5%**。
3. 借主の失火で建物が燃えても、**失火責任法**により重過失がなければ不法行為責任を負わないが、貸主に対する**債務不履行責任**（原状回復義務）は免れないため、借主は**借家人賠償責任保険**に加入する。

## 本文

### 保険の基本用語

- **保険価額**: 保険の対象の評価額（再調達価額または時価）
- **保険金額**: 契約で定める支払限度額。保険価額より多い**超過保険**、少ない**一部保険**
- **免責金額**: 自己負担額
- **告知義務**: 契約時に重要事項（建物の構造、用途など）を正しく告げる義務
- **通知義務**: 契約後に危険が増加したとき（用途変更など）に通知する義務
- 損害保険は**実損てん補**が原則（実際の損害額を限度に支払う）

### 火災保険

**補償対象**: 建物、家財（それぞれ別に契約）

**補償する事故**（契約により選択）
- 火災、落雷、破裂・爆発
- 風災・雹災・雪災
- 水災（洪水、土砂崩れ）
- 水濡れ（給排水設備の事故による）
- 盗難、騒擾、外部からの物体の衝突
- 破損・汚損（うっかり事故）

**補償しないもの**
- **地震・噴火・津波**による損害（地震による火災も含む）→ 地震保険
- 経年劣化、シロアリ、故意による損害

貸主は建物に火災保険をかけ、借主は自分の家財に火災保険をかけます。

### 地震保険

| 項目 | 内容 |
|---|---|
| 加入方法 | **火災保険に付帯**して加入（単独では加入できない） |
| 対象 | 居住用建物と家財 |
| 保険金額 | 火災保険の保険金額の**30〜50%**の範囲。上限は建物**5,000万円**、家財**1,000万円** |
| 保険料 | **都道府県**と建物の**構造**（イ構造: 耐火、ロ構造: 非耐火）で決まる。保険会社による差はない（政府と民間の共同運営） |
| 損害区分 | **全損**: 保険金額の100%、**大半損**: 60%、**小半損**: 30%、**一部損**: 5% |
| 割引 | 建築年割引、耐震等級割引、免震建築物割引、耐震診断割引 |
| 税制 | **地震保険料控除**（所得税最高5万円、住民税最高2.5万円） |

地震保険は損害額を全額補償するものではなく、被災者の**生活再建の一助**という位置づけです。政府が再保険を引き受けています。

### 失火責任法と借家人賠償責任保険

**失火責任法**（失火ノ責任ニ関スル法律）は、失火者に**重大な過失**がある場合を除き、民法709条の不法行為責任を負わないとする法律です。日本では木造住宅が多く延焼しやすいため、軽過失による失火まで賠償責任を負わせるのは酷だからです。

しかし、借主が失火で借りている建物を燃やした場合、借主は貸主に対して**債務不履行責任**（賃借物を返還する義務、原状回復義務）を負います。失火責任法は不法行為責任の免除であって、契約責任には及ばないからです。したがって借主は、この債務不履行責任をカバーする**借家人賠償責任保険**（火災保険の特約）に加入します。

**隣家への延焼**については、借主に重過失がなければ不法行為責任を負わないので、隣家は自分の火災保険で対応します。

### 賠償責任保険の整理

| 保険 | 加入者 | 補償内容 |
|---|---|---|
| **借家人賠償責任保険** | 借主 | 借主の過失で借用戸室に損害を与え、貸主に対して負う賠償責任 |
| **個人賠償責任保険** | 借主 | 日常生活で他人に与えた損害（階下への水漏れ、自転車事故など） |
| **施設所有（管理）者賠償責任保険** | 貸主・管理業者 | 建物の欠陥・管理不備で第三者に与えた損害（外壁タイル落下、共用部での転倒） |
| **家主費用・利益保険（孤独死保険等）** | 貸主 | 入居者の死亡（孤独死・自殺等）による原状回復費用、空室期間の家賃損失 |

賃貸借契約で借主に火災保険（借家人賠償責任保険・個人賠償責任保険付き）の加入を義務づける例が多く、契約更新時に保険の更新も確認します。

### 保険募集の規制

保険の販売（募集）は、**保険募集人**の登録が必要です。管理業者が保険を紹介するだけでなく契約手続や説明を行うには、保険代理店として登録し、募集人資格を持つ必要があります。

## ひっかけポイント

- 「火災保険は、**地震による火災**の損害も補償する」→ 誤り。地震保険が必要。
- 「地震保険は**単独で**加入できる」→ 誤り。火災保険に付帯。
- 「地震保険の保険金額は火災保険の**100%**まで設定できる」→ 誤り。30〜50%。
- 「地震保険の保険料は**保険会社によって異なる**」→ 誤り。都道府県と構造で決まり、会社間の差はない。
- 「借主が軽過失で失火した場合、失火責任法により貸主に対する**債務不履行責任も負わない**」→ 誤り。債務不履行責任は負う。
- 「**借家人賠償責任保険**は、階下への水漏れによる損害を補償する」→ 誤り。個人賠償責任保険。

## 確認問題（○×）

**問1** 火災保険では、地震を原因とする火災による損害は補償されない。

**問2** 地震保険は、火災保険に付帯して契約するものであり、単独で契約することはできない。

**問3** 地震保険の保険金額は、火災保険の保険金額の30%から50%の範囲内で設定し、建物は5,000万円、家財は1,000万円が上限である。

**問4** 借主の軽過失による失火で賃借建物が焼失した場合、失火責任法により、借主は貸主に対する債務不履行責任も免れる。

**問5** 借家人賠償責任保険は、借主の過失により借用戸室に損害を与えた場合に貸主に対して負う賠償責任を補償する。

### 解答と解説

- **問1 ○** 地震を原因とする損害は地震保険の対象。
- **問2 ○** 付帯契約。
- **問3 ○** 地震保険の限度。
- **問4 ×** 失火責任法は不法行為責任のみ免除。債務不履行責任は残る。
- **問5 ○** 借家人賠償責任保険の内容。
