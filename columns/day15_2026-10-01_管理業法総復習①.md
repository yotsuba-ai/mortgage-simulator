# Day 15（2026年10月1日）管理業法 総復習①（登録制度と管理業者の業務）

## 今日のテーマ

第1期の前半（Day 1〜8）を、**一覧表**で総ざらいします。新しい知識はほとんどありません。表を見て「あ、これは覚えていない」と思った項目だけ、該当するDayに戻ってください。

## まず結論

1. 管理業法の数字は「**200戸・5年・90日〜30日・30日・1年・2年**」の6つに集約できる。
2. 書面は「**重説（前・除外あり・罰則なし）**」と「**締結時書面（後・除外なし・30万円）**」の対比で覚える。
3. 罰則は「**1年・100万円**」「**30万円**」「**なし**」の3グループ。

## 本文

### 1. 数字の総整理

| 数字 | 何の数字か | Day |
|---|---|---|
| 200戸 | 登録義務の基準（以上で義務、未満は任意） | 2 |
| 5年 | 登録の有効期間 | 2 |
| 90日前〜30日前 | 更新申請の期間 | 2 |
| 30日以内 | 変更届出、廃業等の届出（死亡は知った日から） | 2 |
| 5年 | 登録拒否事由の経過期間（取消し、禁錮以上、法違反罰金、暴力団員） | 2 |
| 30日以内 | 登録取消しを受けた法人の役員が拒否事由になる期間（取消し前） | 2 |
| 1人以上 | 営業所ごとの業務管理者 | 3 |
| 2年以上 | 業務管理者の実務経験 | 3 |
| 1週間程度 | 重説から契約締結までに置くことが望ましい期間 | 4 |
| 5年 | 帳簿の保存期間（事業年度末閉鎖後） | 6 |
| 1年以内ごと | 定期報告の頻度 | 7 |
| 1年以内 | 業務停止命令の期間 | 8 |
| 1年 | 業務未開始・休止による登録取消しの基準 | 8 |

### 2. 定義の境界線

| 事例 | 該当するか |
|---|---|
| 入居者募集中で空室の住宅 | 賃貸住宅に**該当** |
| 事務所・店舗 | 賃貸住宅に**該当しない** |
| 現に民泊営業中の届出住宅 | 賃貸住宅に**該当しない** |
| 維持保全＋金銭管理の受託 | 管理業務に**該当** |
| 金銭管理のみの受託 | 管理業務に**該当しない** |
| 清掃のみ、エレベーター保守のみ | 管理業務に**該当しない** |
| 苦情対応のみ | 管理業務に**該当しない** |
| サブリース業者がオーナーから維持保全を受託 | 管理業務に**該当** |

### 3. 登録拒否事由の整理

| 分類 | 内容 | 経過期間 |
|---|---|---|
| 本人の状態 | 心身の故障、破産者で復権を得ない | 回復・復権まで |
| 過去の処分 | 登録取消し（法人なら取消し前30日以内の役員も） | 5年 |
| 刑罰 | 禁錮以上の刑（罪名を問わない） | 5年 |
| 刑罰 | 管理業法違反による罰金刑 | 5年 |
| 暴力団 | 暴力団員、暴力団員でなくなった者 | 5年 |
| 周囲 | 未成年者の法定代理人、法人の役員、事業を支配する暴力団員等 | 上記に準ずる |
| 体制 | 業務管理者の確保見込みなし、財産的基礎なし | ― |

### 4. 業務ルール一覧

| 義務 | 主なポイント | 罰則 |
|---|---|---|
| 業務管理者（12条） | 営業所ごと1人以上、兼任不可、欠けたら新規契約不可 | 30万円 |
| 重要事項説明（13条） | 契約前、書面交付、プロは除外、電磁的可、IT重説可 | なし |
| 締結時書面（14条） | 契約後遅滞なく、除外なし、契約書で代用可、重説書と一体不可 | 30万円 |
| 再委託の禁止（15条） | 全部再委託は禁止、一部は契約に定めあれば可 | なし |
| 分別管理（16条） | 固有財産と口座区分、契約ごとに帳簿で判別 | なし |
| 従業者証明書（17条） | 携帯させる、請求あれば提示、派遣社員も | 30万円 |
| 帳簿（18条） | 営業所ごと、委託者ごと、年度末閉鎖後5年保存 | 30万円 |
| 標識（19条） | 営業所ごと、公衆の見やすい場所、ネット不可 | 30万円 |
| 定期報告（20条） | 1年以内ごと＋満了後、実施状況と苦情対応 | なし |
| 秘密保持（21条） | 業者・従業者とも、廃業・退職後も | 30万円（親告罪） |

### 5. 罰則の3グループ

- **1年以下の懲役もしくは100万円以下の罰金、または併科**: 無登録営業、不正登録、名義貸し、業務停止命令違反
- **30万円以下の罰金**: 変更届出、業務管理者、締結時書面、従業者証明書、帳簿、標識、秘密保持、業務改善命令違反、報告・検査拒否
- **罰則なし**: 重要事項説明、再委託、分別管理、定期報告

## ひっかけポイント（総集編）

- 「200戸未満は登録**できない**」→ できる（任意登録）
- 「更新申請は満了日**まで**にすればよい」→ 90日前から30日前まで
- 「死亡届出は**死亡の日**から30日」→ 知った日から
- 「罰金刑はすべて拒否事由」→ 管理業法違反の罰金刑のみ
- 「業務管理者が重説を**しなければならない**」→ 義務ではない
- 「重説書と締結時書面は**一体にできる**」→ できない
- 「帳簿は**3年**保存」→ 5年
- 「分別管理違反は**罰金**」→ 罰則なし
- 「定期報告は**対面**」→ 対面不要

## 確認問題（○×）

**問1** 管理戸数が200戸未満の者は、賃貸住宅管理業の登録を受けることはできるが、登録を受けた場合には賃貸住宅管理業法の規制がすべて適用される。

**問2** 賃貸住宅管理業者は、重要事項説明書と締結時書面を1通の書面にまとめて交付することができる。

**問3** 帳簿は、各事業年度の末日をもって閉鎖し、閉鎖後3年間保存すれば足りる。

**問4** 賃貸住宅管理業者が定期報告義務に違反した場合、30万円以下の罰金に処せられる。

**問5** 賃貸住宅管理業法の規定により罰金の刑に処せられ、その執行を終わった日から5年を経過しない者は、登録を受けることができない。

### 解答と解説

- **問1 ○** 任意登録でも規制は同じ。
- **問2 ×** 別個の書面。
- **問3 ×** 5年。
- **問4 ×** 定期報告義務違反に罰則はない。
- **問5 ○** 管理業法違反の罰金刑は5年間の拒否事由。
