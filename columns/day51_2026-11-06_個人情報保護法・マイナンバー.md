# Day 51（2026年11月6日）個人情報保護法・マイナンバー

## 今日のテーマ

管理業者は、入居者・申込者・オーナーの**個人情報**を大量に扱います。**個人情報保護法**の基本と、賃貸管理の場面での適用（申込書、保証会社への提供、漏えい時の対応）、**マイナンバー**の取扱いを整理します。

## まず結論

1. 個人情報を事業に用いる者は、取扱件数にかかわらず**すべて個人情報取扱事業者**。**利用目的の特定・通知公表**、**目的外利用の禁止**、**安全管理措置**、**第三者提供の制限**（原則本人の同意）が中核の義務。
2. **要配慮個人情報**（人種、信条、病歴、犯罪歴など）の取得には**本人の同意**が必要。
3. 個人データの**漏えい**で本人の権利利益を害するおそれが大きいとき（要配慮個人情報の漏えい、1,000人超の漏えいなど）は、**個人情報保護委員会への報告**と**本人への通知**が義務。

## 本文

### 用語

| 用語 | 内容 |
|---|---|
| **個人情報** | **生存する**個人に関する情報で、氏名・生年月日等により**特定の個人を識別できる**もの（他の情報と容易に照合して識別できるものを含む）、または**個人識別符号**（マイナンバー、免許証番号、顔認証データなど）を含むもの |
| **要配慮個人情報** | 人種、信条、社会的身分、**病歴**、**犯罪の経歴**、犯罪被害、障害、健康診断結果など、不当な差別・偏見が生じないよう特に配慮を要する情報 |
| **個人情報データベース等** | 個人情報を検索できるように体系的に構成したもの（顧客管理システム、入居者名簿など） |
| **個人データ** | 個人情報データベース等を構成する個人情報 |
| **保有個人データ** | 事業者が開示・訂正・削除等の権限を有する個人データ |
| **個人情報取扱事業者** | 個人情報データベース等を事業の用に供している者。令和2年改正前の「5,000件以下は除外」は**廃止**され、件数にかかわらず該当 |

死者の情報は個人情報ではありませんが、遺族の情報として個人情報になることがあります。

### 個人情報取扱事業者の義務

**取得・利用**
- **利用目的をできる限り特定**し、取得時に**通知または公表**（申込書に記載、ウェブサイトに掲載）
- 特定した利用目的の範囲を超えて利用しない（**目的外利用の禁止**）。超える場合は本人の同意
- **適正な取得**（偽りその他不正の手段による取得の禁止）
- **要配慮個人情報**の取得には原則として本人の**同意**が必要
- **不適正な利用の禁止**（違法・不当な行為を助長するおそれのある利用）

**管理**
- 個人データを正確・最新に保ち、不要になれば遅滞なく消去する努力義務
- **安全管理措置**（組織的、人的、物理的、技術的）
- **従業者の監督**、**委託先の監督**

**第三者提供**
- 個人データを第三者に提供するには、原則として**本人の同意**が必要
- 例外: 法令に基づく場合、人の生命・身体・財産の保護に必要で本人の同意を得ることが困難な場合、**オプトアウト**（個人情報保護委員会への届出。要配慮個人情報は不可）など
- **第三者に当たらない**場合: **委託**に伴う提供（管理業者から清掃業者への入居者情報の提供など）、**事業の承継**、**共同利用**（あらかじめ通知・公表）
- 第三者提供の**記録**の作成・保存（提供者・受領者とも）
- 外国の第三者への提供は別途の同意等が必要

**本人の権利**
- 保有個人データの**開示・訂正・追加・削除・利用停止**の請求に応じる
- 開示は電磁的記録での提供も選択可

### 漏えい等の報告・通知（令和4年施行）

次の場合、**個人情報保護委員会への報告**（速報3〜5日以内、確報30日以内）と**本人への通知**が義務です。

- **要配慮個人情報**の漏えい等
- 不正利用により**財産的被害**が生じるおそれがある漏えい等（クレジットカード番号など）
- **不正の目的**による漏えい等（サイバー攻撃、従業員の持出し）
- **1,000人を超える**漏えい等

### 賃貸管理での適用場面

| 場面 | 対応 |
|---|---|
| 入居申込書の取得 | 利用目的（入居審査、契約管理、保証会社・貸主への提供）を明記 |
| **保証会社**への申込者情報の提供 | **第三者提供**に当たるため、本人の**同意**（申込書に同意欄） |
| **貸主**への入居者情報の提供 | 管理受託契約に基づく提供で、利用目的として明示しておく |
| 清掃・設備業者への入居者情報提供 | **委託**に伴う提供で同意不要だが、委託先の監督が必要 |
| 入居者からの他の入居者の情報照会 | 本人の同意なく提供しない |
| 警察からの照会 | 法令に基づく場合（刑事訴訟法197条の捜査関係事項照会）は同意不要 |
| 審査に落ちた申込者の書類 | 不要になったら適切に**廃棄**（シュレッダー等） |
| 病歴・障害・国籍等 | 要配慮個人情報。審査に必要な範囲を超えて取得しない |
| **緊急連絡先**の情報 | 緊急連絡先本人の個人情報でもあるので、利用目的を限定 |

管理業法の**秘密保持義務**（Day 7）と重なる部分もありますが、個人情報保護法は個人データの取扱い全般を規律する点で範囲が広いです。

### マイナンバー（番号法）

- マイナンバー（個人番号）は**特定個人情報**として、個人情報保護法より厳格に規制される
- 利用範囲は**税・社会保障・災害対策**に法定された事務に限られ、本人の同意があっても他の目的で利用・収集できない
- 賃貸管理での関連場面: 法人が個人のオーナーに年間**15万円を超える**家賃を支払う場合、**不動産の使用料等の支払調書**にオーナーのマイナンバーを記載して税務署に提出する必要があるため、オーナーからマイナンバーを収集する（本人確認が必要）
- 入居者からマイナンバーを収集する必要は通常ない。本人確認書類として**マイナンバーカードの表面**を使うのは可能だが、**裏面（番号）をコピーしてはならない**
- 収集したマイナンバーは、必要がなくなれば速やかに廃棄する

## ひっかけポイント

- 「取り扱う個人情報が**5,000件以下**の事業者は個人情報取扱事業者に当たらない」→ 誤り。件数要件は廃止。
- 「**死者**の情報も個人情報に含まれる」→ 誤り。生存する個人の情報。
- 「保証会社に申込者の情報を提供する場合、本人の同意は**不要**」→ 誤り。第三者提供として同意が必要。
- 「清掃業者に入居者の情報を提供することは**第三者提供**に当たり同意が必要」→ 誤り。委託に伴う提供。
- 「**要配慮個人情報**はオプトアウトにより第三者提供できる」→ 誤り。不可。
- 「マイナンバーは本人の**同意があれば**入居審査に利用できる」→ 誤り。法定事務以外に利用不可。

## 確認問題（○×）

**問1** 個人情報保護法上、取り扱う個人情報の件数にかかわらず、個人情報データベース等を事業の用に供している者は個人情報取扱事業者に該当する。

**問2** 病歴や犯罪の経歴は要配慮個人情報に該当し、その取得には原則として本人の同意が必要である。

**問3** 賃貸住宅管理業者が入居申込者の情報を家賃債務保証会社に提供する場合、原則として本人の同意が必要である。

**問4** 個人データの取扱いを委託することに伴って委託先に個人データを提供する場合、本人の同意は不要である。

**問5** マイナンバーは、本人の同意があれば、入居審査の目的で収集・利用することができる。

### 解答と解説

- **問1 ○** 件数要件は廃止。
- **問2 ○** 要配慮個人情報。
- **問3 ○** 第三者提供。
- **問4 ○** 委託は第三者提供に当たらない。
- **問5 ×** 法定事務以外の利用は同意があっても不可。
