# Day 27（2026年10月13日）原状回復（ガイドライン・経年劣化・特約の有効要件）

## 今日のテーマ

退去時の**原状回復**は、賃貸管理で最もトラブルが多い分野で、試験でも毎年2問前後出ます。民法621条の原則と、国土交通省「原状回復をめぐるトラブルとガイドライン」の考え方、特約の有効要件を整理します。

## まず結論

1. 借主は、**通常損耗と経年変化を除く**損傷を原状回復する義務を負う。借主の責めに帰することができない損傷も除く（民法621条）。
2. ガイドラインでは、借主負担となる部分についても**経過年数**を考慮して負担割合を減らす（クロス・カーペット・クッションフロアは**6年で残存価値1円**）。ただし**フローリングの部分補修**や**鍵の紛失**は経過年数を考慮しない。
3. 通常損耗を借主負担とする特約は、借主が**負担の内容と範囲を明確に認識し、合意**していることが必要（最判平成17年12月16日）。

## 本文

### 民法621条の原則

借主は、賃借物を受け取った後に生じた**損傷**がある場合、賃貸借終了時にその損傷を原状に復する義務を負います。ただし次のものは除きます。

- **通常の使用収益によって生じた損耗**（通常損耗）
- **経年変化**
- **借主の責めに帰することができない事由**による損傷

通常損耗・経年変化は賃料に織り込まれているという考え方です。

### ガイドラインの負担区分

| 貸主負担（通常損耗・経年変化） | 借主負担（故意・過失、善管注意義務違反） |
|---|---|
| 家具の設置による床・カーペットのへこみ | 引越作業で生じた引っかき傷 |
| 日照による畳・クロスの変色 | タバコのヤニ・臭い（通常のクリーニングで除去できない程度） |
| テレビ・冷蔵庫の背面の電気ヤケ | 結露を放置したことによるカビ・シミの拡大 |
| 壁の画鋲・ピンの穴（下地ボードの張替えが不要な程度） | 壁のくぎ穴・ネジ穴（下地ボードの張替えが必要な程度） |
| エアコン設置による壁のビス穴 | ペットによる柱・クロスの傷、臭い |
| 鍵の取替え（破損・紛失がない場合） | 鍵の紛失・破損による取替え |
| 専門業者による全体のハウスクリーニング（借主が通常の清掃を行っている場合） | 借主が清掃を怠ったことによる台所の油汚れ、風呂・トイレの水垢・カビ |
| 設備の寿命による故障 | 落書き、飲み物をこぼしたことによるカーペットのシミ |

### 経過年数の考慮

借主負担となる損傷でも、その物の**経過年数**に応じて価値が下がっているため、借主の負担割合は減ります。ガイドラインは減価償却の考え方を使い、耐用年数経過時の残存価値を**1円**として、経過年数に応じた負担割合を定めています。

| 対象 | 耐用年数 |
|---|---|
| クロス（壁紙）、カーペット、クッションフロア | **6年** |
| エアコン、冷蔵庫、ガス機器などの設備 | 6年 |
| 流し台 | 5年 |
| 便器、洗面台などの給排水・衛生設備 | 15年 |
| 畳床、ユニットバス、浴槽 | 建物の耐用年数まで |

**経過年数を考慮しないもの**
- **フローリング**の部分補修（床全体の張替えは建物の耐用年数を考慮）
- **畳表**、襖紙、障子紙（消耗品）
- **鍵**の紛失・破損による取替え
- **クリーニング**費用（借主負担となる場合）

入居時に新品でなかった場合は、入居時点の経過年数から起算します。

### 施工単位

借主負担となる場合でも、可能な限り**損傷部分に限定**して負担させるのが原則です。クロスは㎡単位が原則ですが、色合わせのため**1面分**まで認められることがあります。畳は1枚単位、フローリングは㎡単位（部分補修）が原則です。

### 特約の有効要件

通常損耗の補修費用を借主に負担させる特約（通常損耗補修特約）は、借主に**通常の原状回復義務を超える負担**を課すものです。判例は、このような特約が有効であるためには、①借主が補修費用を負担することになる通常損耗の**範囲が契約書に具体的に明記**されているか、②貸主が口頭で説明し借主が**明確に認識して合意**していることが必要としました（最判平成17年12月16日）。

ガイドラインは、特約が有効となる要件を次の3つにまとめています。
1. 特約の必要性があり、暴利的でないなど**客観的・合理的理由**があること
2. 借主が特約によって通常の原状回復義務を超えた**修繕等の義務を負うことを認識**していること
3. 借主が特約による**義務負担の意思表示**をしていること

**クリーニング特約**は、金額や範囲が明確で、上記要件を満たせば有効とされる例が多いです。「退去時クリーニング費用として〇万円を借主が負担する」と契約書に明記し、説明する運用が一般的です。

### 実務上の対応

- 入居時・退去時に**立会い**を行い、**チェックリスト**と**写真**で状態を記録する
- 退去時の精算では、負担区分と経過年数を反映した**精算書**を交付し、内訳を明示する
- 敷金（Day 22）から控除する場合も同じ

## ひっかけポイント

- 「借主は、**通常損耗を含めて**原状に回復する義務を負う」→ 誤り。
- 「クロスの張替え費用は、経過年数にかかわらず借主が**全額**負担」→ 誤り。6年で残存価値1円。
- 「フローリングの部分補修費用は、**経過年数を考慮**して借主負担額を減額する」→ 誤り。考慮しない。
- 「鍵の紛失による取替え費用は、**経過年数を考慮**する」→ 誤り。
- 「通常損耗を借主負担とする特約は、契約書に**記載があれば**有効」→ 不十分。範囲の明確化と借主の認識・合意が必要。
- 「壁に画鋲を刺した穴は借主負担」→ 原則貸主負担（下地ボード張替えが不要な程度）。

## 確認問題（○×）

**問1** 賃借人は、通常の使用収益によって生じた賃借物の損耗および経年変化については、原状回復義務を負わない。

**問2** 国土交通省の原状回復ガイドラインによれば、クロスの張替え費用を賃借人が負担する場合、6年で残存価値が1円となるように経過年数を考慮する。

**問3** 国土交通省の原状回復ガイドラインによれば、フローリングの部分補修費用については、経過年数を考慮しない。

**問4** 通常損耗の補修費用を賃借人に負担させる特約は、賃借人が特約により通常の原状回復義務を超えた負担を負うことを認識し、その旨の合意をしていなくても、契約書に記載があれば有効である。

**問5** 国土交通省の原状回復ガイドラインによれば、テレビや冷蔵庫の背面の壁の黒ずみ（電気ヤケ）は、賃借人負担とされる。

### 解答と解説

- **問1 ○** 621条。
- **問2 ○** ガイドラインの経過年数の考え方。
- **問3 ○** 部分補修は経過年数を考慮しない。
- **問4 ×** 明確な認識と合意が必要（最判平成17年12月16日）。
- **問5 ×** 通常損耗として貸主負担。
