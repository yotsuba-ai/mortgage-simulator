# 賃貸不動産経営管理士試験 毎日コラム

賃貸不動産経営管理士試験の合格を目指して、毎日1テーマずつ読み切れる学習コラムを蓄積していくフォルダです。

- 対象試験: 令和8年度 賃貸不動産経営管理士試験（例年11月第3日曜日実施。2026年は **11月15日（日）** の見込み。必ず公式サイトで日程を確認してください）
- 開始日: 2026年9月17日（Day 1）
- 計画: 試験前日の11月14日（Day 59）まで毎日1本、試験当日（Day 60）は最終チェックのみ
- 出典: 賃貸住宅管理業法・借地借家法・民法などの条文、国土交通省の「解釈・運用の考え方」、公開されている試験の出題範囲・過去の出題傾向をもとに、独自の文章で執筆しています。特定の市販テキストの文章は使っていません。
- 法改正: 条文・数字は執筆時点の理解で書いています。直近の法改正が試験範囲に含まれる場合は、公式の最新情報で必ず確認してください。

## コラムの構成（毎回共通）

1. **今日のテーマ** と、試験でどのくらい出るか
2. **まず結論**（3行で押さえる要点）
3. **本文**（制度の仕組みを「なぜそうなっているか」から理解する）
4. **ひっかけポイント**（過去の出題で狙われやすい言い回し）
5. **確認問題**（○×5問と解説）
6. **明日の予告**

1本あたり約2,000〜3,000字、通勤時間や寝る前の15分で読み切れる分量を目安にしています。

## ファイル名の規則

`dayNN_YYYY-MM-DD_テーマ.md`（例: `day01_2026-09-17_管理業法の全体像と定義.md`）

## 学習計画（全59本）

出題数の配分（賃貸住宅管理業法が約4割、賃貸借が約2割、維持保全が約2割、金銭管理・実務が約2割）に合わせて日数を振り分けています。
