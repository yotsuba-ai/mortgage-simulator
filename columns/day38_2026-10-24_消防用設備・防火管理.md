# Day 38（2026年10月24日）消防用設備・防火管理（消防法・住宅用火災警報器）

## 今日のテーマ

**消防法**に基づく防火管理と消防用設備です。火災は人命に直結するため、管理業者の責任も重大です。「防火管理者は収容人員50人以上」「住宅用火災警報器は全住宅に設置義務」「点検は6か月・1年、報告は3年」を軸に整理します。

## まず結論

1. 共同住宅（非特定防火対象物）は、**収容人員50人以上**で**防火管理者**の選任が必要。防火管理者は**消防計画**を作成して消防長・消防署長に届け出、消防訓練を実施する。
2. 消防用設備の設置基準は延べ面積で決まり、共同住宅では**消火器150㎡以上**、**自動火災報知設備500㎡以上**、**屋内消火栓700㎡以上**、**スプリンクラー11階以上の階**が目安。
3. **住宅用火災警報器**は、消防法により**すべての住宅**（共同住宅を含む）の**寝室**と**寝室のある階の階段**に設置義務。設置・維持の義務者は所有者・管理者・占有者。

## 本文

### 防火対象物の区分

消防法は建物を、不特定多数の人が出入りする**特定防火対象物**（劇場、飲食店、店舗、ホテル、病院、老人福祉施設など）と、それ以外の**非特定防火対象物**（**共同住宅**、事務所、学校、工場など）に分けます。特定防火対象物のほうが規制が厳しく、共同住宅は非特定です。

### 防火管理者

| 項目 | 内容 |
|---|---|
| 選任が必要な建物 | 非特定防火対象物（共同住宅など）: **収容人員50人以上**。特定防火対象物: 30人以上（一部は10人以上） |
| 選任義務者 | **管理について権原を有する者**（所有者、管理会社など） |
| 資格 | 甲種または乙種**防火管理講習**の修了者など。延べ面積500㎡以上の非特定防火対象物は甲種 |
| 業務 | **消防計画**の作成・届出、**消防訓練**（消火・通報・避難）の実施、消防用設備の点検・整備、避難・防火上必要な構造・設備の維持管理、火気の使用の監督 |
| 届出 | 選任・解任したときは遅滞なく消防長または消防署長に届出 |

収容人員の算定は、共同住宅では居住者数（各住戸の居住者の合計）で行います。一棟の建物に複数の管理権原者がいる場合（分譲店舗併用など）は、**統括防火管理者**が必要になることがあります。

### 消防用設備の設置基準（共同住宅の目安）

| 設備 | 設置基準（共同住宅） |
|---|---|
| **消火器** | 延べ面積**150㎡以上**（各階、歩行距離20m以内に配置） |
| **自動火災報知設備** | 延べ面積**500㎡以上**、または11階以上の階 |
| **屋内消火栓設備** | 延べ面積**700㎡以上**（耐火構造の場合は緩和あり） |
| **スプリンクラー設備** | **11階以上の階** |
| **避難器具** | 2階以上で収容人員30人以上など（階・収容人員により） |
| **誘導灯・誘導標識** | 11階以上の階、地階、無窓階など（共同住宅は緩和あり） |
| **非常警報設備** | 収容人員50人以上など |
| **連結送水管** | 7階建て以上、または5階建て以上で延べ面積6,000㎡以上 |

数値は自治体条例で上乗せされることがあります。「特定共同住宅等」の基準（省令40号）を満たす構造の共同住宅は、設備の設置が緩和されます。

### 点検と報告（Day 31の復習）

- **機器点検**: **6か月**に1回
- **総合点検**: **1年**に1回
- **報告**: 共同住宅（非特定）は**3年に1回**、特定防火対象物は1年に1回
- 延べ面積1,000㎡以上（非特定は消防長等が指定するもの）は**消防設備士**または**消防設備点検資格者**が点検

### 住宅用火災警報器

消防法により、**すべての住宅**（戸建て・共同住宅の各住戸）に**住宅用火災警報器**の設置が義務づけられています（既存住宅を含む）。ただし、自動火災報知設備やスプリンクラー設備が設置されている住戸は免除されます。

- 設置場所: **寝室**、**寝室のある階の階段**（避難経路）。市町村条例で**台所**などを追加している場合が多い
- 種類: 煙式（寝室・階段）、熱式（台所など条例で認められる場合）
- 設置・維持の義務者: 住宅の**関係者（所有者、管理者、占有者）**。賃貸住宅では貸主が設置し、入居者が日常の点検（テストボタン）を行うのが一般的
- 電池寿命は約10年で、交換が必要
- 罰則はないが、火災による死者の多くが逃げ遅れであり、早期発見に有効

### 防炎規制・避難経路

- 高さ**31mを超える**高層建築物では、カーテン・じゅうたんなどに**防炎物品**の使用が義務
- 共用の廊下・階段・避難ハッチの周囲に**物を置かせない**（避難障害）。バルコニーの隔て板（蹴破り戸）の前にも物を置かない
- 消防用設備の前に物を置かない、防火戸の前に物を置かない
- 消防用設備等の設置は、着工前に消防長等に届け出て、完成後に検査を受ける

### 火災時の対応

1. 大声で周囲に知らせ、**119番通報**（通報が最優先）
2. 初期消火は天井に火が届く前まで。それ以上は避難
3. 避難時はエレベーターを使わず階段で。煙を吸わないよう低い姿勢
4. 管理業者は、入居者の安否確認、消防への情報提供、オーナー・保険会社への連絡

## ひっかけポイント

- 「共同住宅は**特定防火対象物**」→ 誤り。非特定。
- 「共同住宅で防火管理者が必要なのは収容人員**30人以上**」→ 誤り。50人以上。
- 「防火管理者の選任義務者は**入居者**」→ 誤り。管理権原者。
- 「住宅用火災警報器は、**新築住宅にのみ**設置義務がある」→ 誤り。既存住宅も含めすべての住宅。
- 「住宅用火災警報器は**台所**に設置が義務づけられている（消防法）」→ 不正確。消防法上は寝室と階段。台所は条例。
- 「防炎物品の使用義務は高さ**20m**を超える建物」→ 誤り。31m。

## 確認問題（○×）

**問1** 共同住宅は、消防法上の非特定防火対象物である。

**問2** 収容人員が50人以上の共同住宅では、管理について権原を有する者は防火管理者を選任し、消防計画を作成させなければならない。

**問3** 消防法上、住宅用火災警報器の設置が義務づけられているのは、新築の住宅に限られる。

**問4** 消防法により、住宅用火災警報器は寝室および寝室がある階の階段に設置しなければならない。

**問5** 共同住宅の共用廊下や階段は避難経路であるため、入居者の私物を置かせないよう管理する必要がある。

### 解答と解説

- **問1 ○** 不特定多数が出入りしないため非特定。
- **問2 ○** 防火管理者の選任基準。
- **問3 ×** 既存住宅を含むすべての住宅。
- **問4 ○** 台所などは条例で追加される。
- **問5 ○** 避難障害の防止。
