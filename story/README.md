# 『ソラノハテ商會』 ─ オリジナル物語一式

> Skyfall Salvage Company
> 十年に一度、空が脱皮する世界。堕ちてきた光には、誰かの失われた記憶が宿っている。

画像生成（ChatGPT のイマジン等）と動画生成（Seedance）での制作を前提に、
**物語 → キャラクターシート → 映像プロンプト** まで一本で繋がるよう構成した制作パッケージです。

## 読む順番

1. **[00_series-bible.md](00_series-bible.md)** — まず世界観と共通ビジュアルガイドを押さえる
2. **[01_plot.md](01_plot.md)** — 全12話の流れを掴む
3. **[characters/README.md](characters/README.md)** — 画像生成のワークフローを確認
4. **[characters/01_akari.md](characters/01_akari.md)** — 主人公の基準画を1枚作ってみる
5. **[seedance/shotlist_ep1.md](seedance/shotlist_ep1.md)** — その画像で動画を1本作ってみる

---

## すぐ試すなら（最短ルート）

1. [characters/01_akari.md](characters/01_akari.md) の **「5-1 基準画」English プロンプト**をそのまま画像生成に投げる
2. 気に入る顔が出るまで作り直す。**採用した1枚が今後すべての「正」**
3. その画像を添付して [seedance/shotlist_ep1.md](seedance/shotlist_ep1.md) の **C-11**（海中を潜るカット）を Seedance へ
4. 10秒のクリップが出る。これが第1話の映像的な山です

## 設計上のポイント

| 論点 | この企画での方針 |
|---|---|
| **キャラの同一性が崩れる** | 各シートに「一貫性キー」（6〜10語の短い呪文）と「絶対に変えない3点」を明記。長文の設定は画像生成で無視されるため、短文を冒頭に置く運用にしている |
| **画風がバラつく** | シリーズバイブルに「共通スタイル文」と「共通ネガティブ」を用意。全プロンプトの末尾に貼る |
| **動画で顔が溶ける** | キャラの出るカットは全て image-to-video 前提。1クリップ＝1動詞＝1カメラワークで設計済み |
| **口パクが破綻する** | 会話シーンを後ろ姿・引き・手元の構図で設計。第1話 S8 が典型例 |
| **遠景でキャラを見分けられない** | 全キャラにシルエット識別要素を設定（灯＝非対称の一房 / レン＝黒い右腕 / ミカ＝引きずる上着 など） |

## 拡張の方向

- **第5話「空鯨の腹の中」を先に映像化する** — 台詞なし・顔アップ少・抽象的で、
  生成AIの弱点を全部回避できるため、PV単体として最も成立しやすい
- **前日譚**（千歳とレンの十年前）を短編2話で
- **外伝**：シオン視点の映像詩（[characters/06_shion.md](characters/06_shion.md) の体内シーンが起点）
