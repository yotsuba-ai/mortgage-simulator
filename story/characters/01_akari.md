## 2. 背景（Background）

七歳のとき、三度目の空脱の最中に**アマベの浜に倒れていた**ところを千歳に拾われた。
それ以前の記憶がない。本人は「事故で頭を打った」と説明されて育ち、疑ったことがない。

商會で育ち、十歳から海に潜り始めた。素潜りで水深18mまで行ける。
灯（ともし）に触れると中の記憶が映像として流れ込む体質を持つが、
これは町の誰も持たない稀有な能力で、商會の稼ぎの根幹になっている。
そのため彼女は**「自分は役に立つから置いてもらえている」** と無意識に信じている。

- **表の欲求**：拾った灯を、正しい持ち主に返したい。
- **裏の欲求**：自分がここにいていい理由が欲しい。
- **傷**：自分が「誰か」であるという確信がない。
- **アーク**：役に立つ自分 → 借りものの自分 → **預かりものを引き受ける自分**。

## 3. 性格・話し方

- 実務的で口数が少ない。感情は言葉より先に身体（走る・潜る・作る）に出る。
- 目上には丁寧語、レンには対等なぞんざい語、ミカには意識して柔らかく。
- 照れると**海の話にすり替える**癖。
- 口癖：「……ん」「返してくる」「それ、私が視る」

**台詞サンプル**
> 「大丈夫。海の中は、上より静かだから」
> 「返し違えたら終わりなの。だから、ちゃんと視る。ちゃんと視てから返す」
> 「私が誰の記憶でも、この手が拾ったものは、私が拾ったものでしょ」

## 4. 外見仕様（Appearance Spec）

### 顔

| 部位 | 仕様 |
|---|---|
| 輪郭 | 小さめの逆卵型。顎は細いが尖らせない |
| 目 | やや吊り目のアーモンド型。**虹彩＝濃い藍 #24406B**、瞳孔の縁がわずかに青白く光る（灯を視る体質の名残） |
| 眉 | 細く直線的。眉尻が短い。感情が出る唯一のパーツ |
| 睫毛 | 上のみ短く3本描画。下睫毛は描かない |
| 鼻・口 | 小さく控えめ。口角は基本まっすぐ（笑顔は稀少カットとして扱う） |
| 肌 | 日焼けした薄いオリーブ **#D9A87E**。鼻梁と頬にそばかす（左頬にやや多い） |
| 特徴 | **右の眉尻に小さな古傷（縦1cm）**。左耳たぶに小さなほくろ |

### 髪

| 項目 | 仕様 |
|---|---|
| 色 | 濡れ羽色に近い暗い藍黒 **#1E2233**。毛先だけ潮焼けで褪せた **#4A5A6B** |
| 型 | 全体はうなじが見える短さ。**右サイドだけ一房が鎖骨下まで長く**、細い革紐で結ばれている |
| 質感 | 硬めの直毛。常にやや湿っていて、束感が出る |
| 前髪 | 目にかかる長さの厚めの前髪。中央がわずかに割れる |

> **設計意図**：短髪＋一房のロングという非対称シルエットで、遠景でも一目で判別できる。
> 長い一房は「千歳が結んでくれた」ものであり、第8話で自分で切る＝アークの視覚化に使う。

### 服装（通常装 / サルベージ装）

**通常装**
- 生成りの厚手インナー（襟ぐりが広く、鎖骨が見える）
- 深い錆朱 **#C4552F** のショートベスト。左胸に商會の刺繍（幾何学的な波と丸／文字ではない）
- 膝丈の紺のワークショーツ、革のベルト、脛まである編み上げブーツ
- **左手首に4本の色違いの紐**（返した灯の数を数えたもの。話数が進むと増える）

**サルベージ装**
- 明らかに**サイズが2つ大きい**カーキ **#6B6A4E** の防水コート。袖を三重に折っている
- 首から下げた真鍮のゴーグル（レンズはひび入り）
- 腰に網袋、太腿に固定した錆びたナイフ
- 素足に潜水用の薄いソックス（ブーツは船に置く）

> **設計意図**：大きすぎるコートは「レンのお下がり」。彼女の居場所の借りもの感を服で表現。

### 小物

- **硝子瓶（掌サイズ、コルク栓、麻紐）** — 灯を入れる。常に2本持つ
- 真鍮のゴーグル
- 千歳から貰った柄の欠けた木の櫛（懐に入れている）
