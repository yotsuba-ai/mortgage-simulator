# キャラクターシートの使い方（ChatGPT 画像生成 → Seedance 動画化）

---

## 0. シートの構成

各キャラクターシートは以下の6ブロックで統一されています。

1. **プロフィール** — 名前・年齢・役割・一行紹介
2. **背景（Background）** — 生い立ち、動機、傷、変化のアーク
3. **性格・話し方** — 台詞を書くときの指針
4. **外見仕様（Appearance Spec）** — 画像生成の「設計図」。数値・色コードつき
5. **画像生成プロンプト** — 日本語版 / English版 / 三面図・表情差分
6. **一貫性キー（Consistency Keys）** — 何があっても毎回必ず入れる短い呪文

---

## 1. 推奨ワークフロー

```
[1] キャラクターシート
      ↓  「基準画（マスターショット）」プロンプトを投入
[2] ChatGPT 画像生成 で 正面バストアップ を1枚作る   ← ここで顔を確定させる
      ↓  気に入るまで作り直す。採用した1枚が今後の「正」
[3] その画像を添付し「同一人物で」＋差分プロンプト
      → 三面図 / 表情差分 / 全身 / 別衣装 を派生させる
      ↓
[4] 用途別のキーフレーム画像を作る（シーンごとの1枚）
      ↓
[5] Seedance に「画像 + 動きプロンプト」を投入（image-to-video）
      → 5〜10秒クリップ
      ↓
[6] クリップを編集ソフトで連結・音入れ
```

**最重要**：Seedance は text-to-video より **image-to-video** の方がキャラの同一性が保てます。
必ず [2] で確定させた顔を経由してください。

---

## 2. ChatGPT 画像生成でのコツ

| 課題 | 対処 |
|---|---|
| 顔が毎回変わる | 基準画を**添付**して「この人物の同一性を保持して」と明示。文章だけで再現しようとしない |
| 服装が崩れる | 「一貫性キー」の短い呪文（6〜10語）を毎回冒頭に置く。長文の後半は無視されやすい |
| 画風がバラつく | シリーズバイブルの「共通スタイル文」を全プロンプト末尾に固定で貼る |
| 日本語が絵に描かれる | ネガティブに `text, letters, watermark` を入れる。看板類は「文字なし」と指定 |
| 年齢が上下する | 年齢は数字ではなく特徴で指定（例：「丸みのある頬」「首が細い」） |

### プロンプトの推奨並び順

```
[一貫性キー] → [構図・カメラ] → [表情・ポーズ] → [服装] → [背景] → [ライティング] → [画風] → [ネガティブ]
```

---

## 3. Seedance へ渡すときのコツ

- **1クリップ＝1アクション**。「振り向いて、走って、飛ぶ」は破綻します。「ゆっくり振り向く」だけ。
- カメラワークは1つだけ指定（`slow dolly in` / `pan left` / `static` など）。
- 尺は 5秒 を基本、感情の溜めがある画だけ 10秒。
- 会話シーンは**口パクを避ける**構図（後ろ姿・引き・手元）にすると破綻が減ります。
- 詳細は [../seedance/prompt-guide.md](../seedance/prompt-guide.md)

## 4. 全キャラ共通ネガティブ（コピペ用）

```
photorealistic, 3D render, plastic skin, oversaturated colors, heavy lens flare,
text, letters, watermark, logo, extra fingers, deformed hands, extra limbs,
modern clothing brands, harsh frontal flash, cluttered composition
```
