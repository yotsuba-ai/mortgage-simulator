# 04 ─ ミカ／ Mika

> 「ぼく、名前がない」

---

## 1. プロフィール

| 項目 | 内容 |
|---|---|
| 名前 | ミカ（灯が名付けた仮の名。「みかん箱に座っていたから」） |
| 英名表記 | Mika |
| 年齢 | 外見12歳前後。実年齢は存在しない |
| 性別 | 不明（作中で断定しない。三人称は「ミカ」で統一） |
| 身長 / 体格 | 141cm。手足が細く、関節が目立つ。体温がやや低い |
| 役割 | ドリフトチャイルド。物語の器であり、目的地 |
| 一行紹介 | 空から堕ちてきた、記憶をひとつも持たない子ども |

## 2. 背景（Background）

第1話、空脱初日の海中で灯に拾われる。呼吸も脈もあるが、
**言語・記憶・習慣のすべてを持たない**状態で発見された。

ミカは「灯（ともし）」に触れると、その記憶を**自分のものとして吸収**してしまう。
他人の記憶で泣き、他人の癖で箸を持ち、他人の恋を懐かしむ。
その正体は、天海庁が十年前に**破棄した灯の残滓が寄り集まって形を得たもの**——
つまり「誰にも返されなかった記憶たち」の集合体である。

- **表の欲求**：みんなと同じ「ふつうの人」になりたい。
- **裏の欲求**：自分の中の他人を、正しい場所に帰したい。
- **傷**：どの感情も借りものである、という自覚。
- **アーク**：空っぽの器 → 借りもので満ちた器 → **空になり、初めて自分の記憶を持つ**。

## 3. 性格・話し方

- 発見当初は無言。第2話から片言、第5話でほぼ普通に喋るようになる（成長の演出）。
- 覚えた言葉を**そのまま鸚鵡返しに使う**。誰の癖を借りているかで台詞のトーンが変わる。
- 好奇心が強く、危険への感覚がない。熱いものにも平気で触る。
- 口癖：「これ、なに」「……知ってる気がする」「ぼく、それ持ってる」

**台詞サンプル**
> 「これ、しょっぱい。……しょっぱいの、好きだったんだ。だれかが」
> 「泣いてるの、ぼくじゃないよ。ぼくの中の、だれか」
> 「からっぽになったら、ぼく、いなくなる？」

## 4. 外見仕様（Appearance Spec）

### 顔

| 部位 | 仕様 |
|---|---|
| 輪郭 | 丸みのある頬、小さな顎。子どもらしい柔らかさ |
| 目 | 大きく丸い、やや垂れ目。**虹彩＝ほぼ無色の淡い灰白 #D6DDE4**、瞳孔だけが黒く小さい |
| 眉 | 髪と同色で非常に薄く、ほとんど見えない |
| 鼻・口 | 小さく低い鼻。唇は薄く、色が淡い |
| 肌 | **血色の薄い青白 #EDE7E4**。頬にわずかな赤みが差すのは第10話以降のみ |
| 特徴 | **右鎖骨のすぐ下に、淡く発光する小さな環状の紋様**（触れた灯の数だけ環が増える） |

### 髪

| 項目 | 仕様 |
|---|---|
| 色 | 白 **#F2F0EC**。毛先だけがごく淡い青 **#C9DCE4** に透ける |
| 型 | 顎のラインで切りそろえたような不揃いなボブ。跳ねが多い |
| 質感 | 猫毛。細く、光を透かす。逆光で輪郭が光る |
| 前髪 | 眉が隠れる長さ。真ん中がわずかに割れる |

> **設計意図**：白髪＋淡い瞳＋青白い肌で「人ではないかもしれない」を色だけで伝える。
> 第12話で頬に赤みが差す＝人になった、という色彩演出でクライマックスを支える。

### 服装

- **大人サイズのカーキ色の上着**（灯のサルベージコートの予備）。丈が足首まであり引きずる
- 袖から手が出ていない。第4話以降、レンが袖を切ってくれて手が出る（成長の視覚化）
- 中は千歳が縫った白い簡素なワンピース状の衣（縫い目が粗い）
- **裸足**（第9話まで一貫。靴を履くのは投降の場面が初めて＝別れの合図）
- 首に麻紐、先に小さな空の硝子瓶（灯が「きみの分」と渡したもの）
