## 記事フォーマット

各号は次の構成で作成します。

1. **今週の3行まとめ** — 忙しい人がここだけ読めば把握できる要点
2. **本編（6〜8本）** — カテゴリ別。冒頭は「今週の一番」として、その週に新しく公表されたニュースを置く。各項目に以下を必ず含める
   - 数値は表にまとめる（前年比・前月比を併記）
   - 出典（機関名と公表時期）を明記する
   - **読みどころ** — 数字の裏側にある意味の解説。単なる要約で終わらせない
3. **来週以降のウォッチポイント** — 次に見るべき指標・イベント
4. **情報ソース** — 参照元へのリンク一覧

### 執筆時のルール

- 数値には必ず **時点**（○年○月時点、○年上半期など）を添える
- 「首都圏」「東京都」「都心3区」など **集計範囲を混同しない**
- 推測と事実を区別する。推測は「読みどころ」のなかで、そうと分かる書き方をする
- 一次資料が確認できなかった数値は、その旨を注記する
- 住宅ローン金利の話題では、リポジトリ内の [住宅ローンシミュレーター](../index.html) への導線を入れる
